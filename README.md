# 🔍 미디어 리터러시 퀘스트

초등학교 5~6학년을 위한 **미디어·AI 리터러시 교육용 웹 게임 패키지**입니다.
8개의 게임을 학습 순서대로 배치한 2부 8차시 구성으로, 설치·로그인 없이 브라우저만 있으면 실행됩니다.

**1부 · 알고리즘의 비밀**

| 차시 | 게임 | 학습 주제 |
|---|---|---|
| 1차시 | 🧙 알고리즘 설계자 | 피드 알고리즘 이해 — 추천 알고리즘의 기준과 상업적 동기 |
| 2차시 | 🫧 필터버블 탐지기 | 필터버블 체험 — 내 선택이 만드는 정보 편식 |
| 3차시 | 🔮 추천 요정 훈련소 | 사회적 영향 통찰 — 알고리즘의 눈으로 본 추천 |
| 4차시 | 🎛️ 알고리즘 연구소장 | 플랫폼 운영자 관점 — 수익과 책임의 딜레마 |

**2부 · 인공지능과 살아가기**

| 차시 | 게임 | 학습 주제 |
|---|---|---|
| 5차시 | 🍚 데이터 편식쟁이 AI | AI 학습과 데이터 편향 — AI는 먹은 데이터만큼만 안다 |
| 6차시 | 🕵️ 딥페이크 탐정단 | AI 생성물 판별 — 단서 찾기와 출처 확인 |
| 7차시 | ✅ 누리봇 사실 검증단 | AI 답변 검증 — 환각을 자료와 대조해 확인하기 |
| 8차시 | 🧳 내 데이터의 여행 | 개인정보와 맞춤 광고 — 내 클릭이 광고가 되기까지 |

## 특징

- **개인정보 수집 없음**: 로그인·서버 저장이 없으며, 진행 기록은 사용 중인 브라우저(localStorage)에만 남습니다.
- **가상 세계관**: 게임 속 SNS(누리피드), 동영상 플랫폼(누리TV), 인물, 게시물은 모두 교육용으로 창작한 '누리마을' 세계관의 가상 콘텐츠입니다 (`docs/worldview.md`).
- **오프라인·저사양 대응**: 외부 폰트/CDN/API 의존이 없고, 단일 HTML 파일로 만들어 인터넷 없이 실행할 수 있습니다.
- **교사가 직접 수정 가능한 콘텐츠**: 게임 속 게시물·카드·미션은 코드와 분리된 JSON 파일에 있습니다.

## 실행 방법

### 개발/미리보기 (교사·개발자)

```bash
npm install        # 최초 1회
npm run dev        # 개발 서버 (http://localhost:8080)
```

### 배포용 빌드

```bash
npm run build      # dist/ — 웹 서버 업로드용 (data/*.json 수정 가능)
npm run build:offline  # dist-offline/index.html — 단일 파일, 더블클릭 실행
```

- **웹 배포**: `dist/` 폴더를 정적 호스팅(학교 서버 등)에 올리면 URL 접속만으로 실행됩니다.
  - GitHub Pages 배포 워크플로가 준비되어 있지만, 저장소가 비공개인 동안에는 사용할 수 없어 꺼 둔 상태입니다. 저장소를 공개로 전환하면 `.github/workflows/deploy-pages.yml`의 push 트리거 주석을 풀어 자동 배포를 켤 수 있습니다.
- **오프라인 배포**: `dist-offline/index.html` 파일 하나만 USB·메신저로 배포하면, 인터넷 없는 교실 PC에서도 더블클릭으로 실행됩니다.

## 게임 콘텐츠 수정하기 (교사용)

게임에 나오는 게시물·카드·미션 텍스트는 전부 JSON 파일에 있습니다. 코드를 몰라도 메모장으로 열어 고칠 수 있습니다.

- 원본: `src/content/*.json` (수정 후 다시 빌드)
- 웹 배포본: `dist/data/*.json` (수정하면 **재빌드 없이** 바로 반영)

| 파일 | 내용 |
|---|---|
| `feed-algorithm.json` | 1차시 딜레마 카드 8장, 엔딩, 성찰 수칙 |
| `filter-bubble.json` | 2차시 콘텐츠 200개, 분야, 성향 칭호 |
| `social-insight.json` | 3차시 게시물 20개, 난이도, 콤보 문구 |
| `trend-tycoon.json` | 4차시 영상 50개, 미션 5개, 등급 문구, 누리마을의 반응 |
| `data-bias.json` | 5차시 훈련 카드 16장, 시험 문제, 아기봇 대사 |
| `deepfake.json` | 6차시 사건 10건, 단서 사전, 탐정 등급 |
| `fact-check.json` | 7차시 라운드 8개(질문·답변·자료 카드) |
| `data-trail.json` | 8차시 피드 게시물, 프로필 문구, 광고 풀, 지키기 시나리오 |

단, 오프라인 단일 파일 버전은 콘텐츠가 파일 안에 내장되므로 JSON 수정 후 `npm run build:offline`을 다시 실행해야 합니다.

## 프로젝트 구조

```
src/
  portal/       # 통합 포털 (게임 선택 화면, 진행 표시)
  games/        # 4개 게임 (차시별 폴더)
  content/      # 게임 콘텐츠 JSON (교사 수정 가능)
  lib/          # 진행 기록(localStorage)·콘텐츠 로더
  components/   # 공통 UI (게임 셸 등)
```
