## 특히 판단이 필요한 지점 (작성 중 표시해 둔 것)

### 소재 수위 — "성인 소재 순화 유지" 방침으로 남긴 항목
- 2차시: "어른들은 왜 주식 얘기를 할까?", "뽑기에 용돈 다 쓴 결과는?!"(×2),
  "용돈 다 털어 산 물건 공개?!", "해외 직구 상자, 열어 보니 충격?!",
  "공짜 선물 문자, 알고 보니 사기?!"(스미싱 예방), "유명 크리에이터 몰래 광고 논란!"(뒷광고),
  "쓰레기 몰래 버린 사람, 통쾌한 결말!"
- 3차시: "무지개시장에서 용돈을 다 써 버렸어요" (과소비 소재)
- 4차시: "키 크는 영양제 선착순 무료"(어린이 대상 낚시 광고 예시),
  "오늘의 행운 지수를 확인하세요"(운세 순화), 좀비/공포게임 영상 2건(자극도 교육 장치)

### 표현 수위
- 1차시 카드 2 "높은 곳에서 뛰어내리는 '아찔한 챌린지'" — 위험 챌린지 묘사 수위
- 1차시 카드 3 "완벽 얼굴 필터" — 외모 관련 소재 (성형 언급은 제거함)
- 1차시 카드 7(신규) 저격 영상 — "학교 가기가 무서워졌어요" 수위
- 1차시의 어두운 통제실 무드("누군가는 상처받을 수도 있어요") 유지 여부

### 게임 설계 변경 (콘텐츠와 함께 검토)
- 1차시 카드 4(가짜 뉴스)의 승인/거절 방향을 다른 카드와 통일했어요
  (모든 카드에서 오른쪽 승인 = 위험한 선택). 원래는 이 카드만 반대였어요.
- 1차시 카드 6장 → 8장 (7일 플레이 중 중복 감소)

### 문체
- 전체 해요체로 통일했어요. 1차시 통제실 연출부(엔딩 등)도 해요체입니다.

### 2부(5~8차시) 신규 콘텐츠 검토 포인트
- 5차시: 성찰 2단계의 얼굴인식 질문 수위 ("특정한 사람들의 사진만 학습"으로 순화함)
- 6차시(게임 전면 재구축 「완벽한 가짜」): ① 1부 눈 시험의 글 쌍 3개(산책 후기·방문 소감·급식 리뷰)가
  '긴 글=AI', '① 쪽=사람' 같은 잘못된 규칙을 만들지 않는지 — 정답 배치(B·A·A·B·B)와 양쪽 글의
  길이·말투를 비슷하게 맞췄지만, 읽다 보면 규칙이 느껴지는지 확인해 주세요.
  ② 사건 4(요리왕 뚝딱 기프트 코드 요구)의 dangerNote 문구("돈·기프트 코드·비밀번호를 요구하는
  메시지를 받으면, 혼자 판단하지 말고 부모님이나 선생님께 바로 알려요")가 학교의 신고·안내 절차와
  맞는지 확인해 주세요.
  ③ '아직 몰라요' 결론은 네 사건 모두에서 오답 처리돼요 — 게임 안에서는 증거가 충분히 제공되기
  때문("이번 사건은 증거가 충분히 모였어요")인데, 진짜 세상에서는 증거가 모이기 전 판단을 미루는 것이
  좋은 태도이므로 이 차이를 수업에서 보완 설명해야 해요(지도안 6차시 핵심 발문 5번·학습지 6번 문항으로
  반영해 둠). 이 설계 자체가 적절한지도 봐 주세요.
- 7차시: 실세계 과학 상식 5건(문어·꿀벌·북극곰·달·펭귄)의 사실 확인 — 정설만 썼으나 최종 확인 권장
- 8차시: 낚시 광고 "무료 선물 100% 당첨!" 표현 수위, 파트C 선택지 취지

### 3부(9~12차시) 신규 콘텐츠 검토 포인트
- 9차시: 다크패턴을 일부러 '체험'시키는 수위 — 시계 숨기기, 작은 '그만 보기' 버튼,
  뽑기식 '대박 영상' 등을 게임이 직접 재현해요. 강제 종료 시점(18개째 영상)이
  체험으로 충분한지/과한지 확인해 주세요.
- 10차시: 사행성 소재 지도 유의 — '조사·해부' 프레이밍(상술 실험실)을 유지했고
  뽑기를 미화하는 문구(대박, 인생역전 등)는 넣지 않았어요. 미화로 읽힐 수 있는
  표현이 없는지 확인 부탁드려요.
- 11차시: 건강 라운드 2건(키 크기·감기)의 의학 정보 — 보건소 누리집(공식 출처)을
  정답 처리하고, 민간요법·과장 결과는 오답 단서로 뒀어요. 방향이 적절한지 확인해 주세요.
- 12차시: 저격 에피소드 수위 — risky 선택 시 지우가 "…나 잠깐 방에서 나가 있을게."라며
  퇴장하는 장면이 있어요. 또한 이 차시는 채팅 말풍선만 아이들 대화라 반말(안내·피드백은
  해요체)인데, 이 말투 유지 여부도 판단이 필요해요.
