# 11차시 「검색 결과 탐정」 콘텐츠 검수표 (신규)

검색 포털 '누리찾기'에서 의뢰인 6명의 검색 미션을 해결해요. 라운드마다 결과 5개(광고/공식 출처/협찬 후기/근거 없는 답변/낚시성 글)가 나오고, 질문 유형에 따라 정답 방식이 달라요:

- **find-ads**: 광고를 모두 찾아 다중 선택
- **pick-trusted**: 가장 믿을 만한 결과 하나 선택
- **find-sponsor**: 상세 미리보기를 열어 협찬 문구 문장을 탭 (본문 맨 끝, 작은 글씨)

건강 라운드(키 크기·감기)는 반드시 보건소 누리집(공식 출처)이 정답이에요. 모든 사이트·주소·상품은 누리마을 세계관의 가상이에요.
