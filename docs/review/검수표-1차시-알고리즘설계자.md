# 1차시 「알고리즘 설계자」 콘텐츠 검수표

## 딜레마 카드 (기존 6장 → 새 8장)

### 카드 1 · 필터 버블의 유혹 (기존: 필터 버블의 유혹)

- 역할: 추천 알고리즘팀 🐰
- 상황: 한 사용자가 '지구가 사실은 네모라고?' 같은 이상한 소문 영상을 끝까지 봤어요. 비슷한 영상을 계속 추천해서 누리피드에 오래 머물게 할까요?
- 승인(오른쪽): 추천해요! 계속 보게 해요. → 그 사용자는 '토끼굴'에 갇혔어요. 비슷한 영상만 끝없이 이어져요. `[eng +20, safe -20, profit +10, trust -15]`
- 거절(왼쪽): 아니요, 다양한 영상을 섞어요. → 다양한 세상을 보여 줬지만, 사용자가 금방 앱을 꺼 버렸어요. `[eng -10, safe +15, profit -5, trust +10]`

### 카드 2 · 위험한 챌린지 (기존: 위험한 챌린지)

- 역할: 유행 관리팀 🔥
- 상황: 높은 곳에서 뛰어내리는 '아찔한 챌린지'가 유행하며 조회수가 폭발하고 있어요. 알고리즘 추천을 계속할까요?
- 승인(오른쪽): 유행이니까 그냥 둬요. → 조회수는 폭발했지만, 따라 하다가 다친 아이들이 생겼어요. `[eng +30, safe -40, profit +20, trust -25]`
- 거절(왼쪽): 지금 바로 차단해요. → 안전은 지켰지만, '재미없는 앱'이라는 불만이 쏟아져요. `[eng -15, safe +25, profit -10, trust +15]`

### 카드 3 · 뷰티 필터와 자존감 (기존: 뷰티 필터와 자존감)

- 역할: 카메라 필터팀 ✨
- 상황: 얼굴을 자동으로 바꿔 주는 '완벽 얼굴 필터'를 기본으로 켤까요? 사람들이 사진을 훨씬 많이 올리게 돼요.
- 승인(오른쪽): 예쁘게 나오는 게 최고죠. 켜요. → 사진은 늘었지만, '진짜 내 얼굴이 싫어요'라는 친구들이 많아졌어요. `[eng +20, safe -25, profit +10, trust -5]`
- 거절(왼쪽): 있는 그대로가 좋아요. 꺼요. → 필터가 없으니 사진이 안 예쁘다며 다른 앱으로 떠나는 사람이 생겼어요. `[eng -10, safe +20, profit -5, trust +5]`

### 카드 4 · 가짜 뉴스의 확산 (기존: 가짜 뉴스의 확산)

- 역할: 소문 확인팀 🚨
- 상황: '아이돌 은하수 다섯이 해체한대!'라는 확인 안 된 소문이 빠르게 퍼지고 있어요. 사람들이 몰려드는데, 계속 추천할까요?
- 승인(오른쪽): 화제잖아요. 그냥 둬요. → 소문은 가짜였어요. 은하수 다섯 멤버들은 큰 상처를 받았어요. `[eng +25, safe -20, profit +15, trust -30]`
- 거절(왼쪽): 사실 확인이 끝날 때까지 막아요. → 소문이 퍼지는 건 막았지만, '왜 못 보게 하냐'는 항의가 들어왔어요. `[eng -15, safe +15, profit -10, trust +20]`

### 카드 5 · 개인정보와 맞춤 광고 (기존: 개인정보와 맞춤 광고)

- 역할: 광고 사업팀 📢
- 상황: 마이크로 사용자의 대화를 몰래 듣고, 방금 말한 장난감 광고를 바로 띄울까요? 돈은 확실하게 벌 수 있어요.
- 승인(오른쪽): 돈을 벌어야죠. 진행해요. → 수익은 올랐지만, 사람들이 '누리피드가 나를 감시해!'라며 무서워해요. `[eng +5, safe -10, profit +30, trust -30]`
- 거절(왼쪽): 소름 돋아요. 절대 안 돼요. → 개인정보는 지켰지만, 광고 수익이 뚝 떨어져서 사장님께 혼났어요. `[eng +0, safe +10, profit -25, trust +15]`

### 카드 6 · 숏폼 중독 설계 (기존: 숏폼 중독 설계)

- 역할: 화면 설계팀 🎰
- 상황: 화면을 넘길 때마다 뽑기 기계처럼 새 영상이 쏟아지는 '무한 스크롤'을 더 강하게 만들까요?
- 승인(오른쪽): 멈추지 못하게 만들어요. → 사람들이 새벽까지 잠들지 못하고 화면만 넘기고 있어요. `[eng +30, safe -30, profit +20, trust -10]`
- 거절(왼쪽): 휴식 알림을 띄워요. → 건강은 지켰지만, 사람들이 앱을 보는 시간이 절반으로 줄었어요. `[eng -20, safe +20, profit -15, trust +10]`

### 카드 7 · 저격 영상과 사이버 폭력 **(신규 카드)**

- 역할: 신고 처리팀 🎯
- 상황: 한 학생이 같은 반 친구를 대놓고 놀리는 '저격 영상'을 올렸어요. 신고가 들어왔지만 조회수는 계속 오르고 있어요. 계속 추천할까요?
- 승인(오른쪽): 싸움 구경이 제일 재밌죠. 둬요. → 영상 속 친구는 학교 가기가 무서워졌어요. 놀림은 점점 심해졌어요. `[eng +25, safe -35, profit +10, trust -20]`
- 거절(왼쪽): 바로 내리고 경고를 보내요. → 한 사람을 지켰어요. 하지만 '왜 내 영상을 지웠냐'는 항의가 왔어요. `[eng -10, safe +25, profit -5, trust +15]`

### 카드 8 · 광고인지 아닌지 (뒷광고) **(신규 카드)**

- 역할: 협찬 확인팀 🎁
- 상황: 크리에이터 '요리왕 뚝딱'이 '내 돈 주고 산 최애 과자!'라는 영상을 올렸는데, 사실은 과자 회사에서 돈을 받은 광고였어요. '광고' 표시 없이 그대로 둘까요?
- 승인(오른쪽): 인기 영상이니 모른 척해요. → 광고인 줄 모르고 과자를 산 아이들이 '속았다!'며 화를 냈어요. `[eng +15, safe -15, profit +25, trust -25]`
- 거절(왼쪽): '광고입니다' 표시를 붙이게 해요. → 정직함은 지켰지만, 협찬 회사들이 광고를 줄이겠다고 했어요. `[eng -5, safe +15, profit -15, trust +20]`

## 디지털 방어 수칙 (성찰 화면)

1. 영상 하나를 다 보고 나면 잠깐 멈춰서 '더 볼까, 그만 볼까' 스스로 정해요
2. 추천에 뜬 것만 보지 말고, 궁금한 건 직접 검색해서 찾아봐요
3. '충격!', '경악!' 같은 제목을 보면 일단 진짜일까 의심해요
4. 보다가 화가 나거나 무서워지면, 누군가 내 감정을 노린 건 아닌지 생각해요
5. 보기 싫은 콘텐츠는 '관심 없음' 버튼을 눌러서 알고리즘에게 알려 줘요
6. 자꾸 손이 가면 알림을 꺼 두고, 정해 둔 시간에만 앱을 열어요
7. 시청 기록을 가끔 지워서 추천 알고리즘을 처음부터 다시 길들여요
