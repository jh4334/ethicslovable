## 단서 사전 8종

| 단서 | 설명 |
|---|---|
| 손가락 개수 오류 | AI는 손을 잘 못 그려요. 손가락이 6개거나 이상하게 붙어 있으면 의심해요! |
| 뭉개진 글자 | 간판이나 현수막의 글자가 구불구불, 읽을 수 없게 뭉개져 있으면 AI가 만든 그림일 수 있어요. |
| 뭉개진 배경 얼굴 | AI는 주인공은 잘 그려도, 배경에 있는 사람들의 얼굴은 녹은 것처럼 뭉개 놓곤 해요. |
| 이상한 그림자 | 그림자는 해의 반대쪽에 생겨요. 그림자가 해와 같은 쪽으로 나 있다면 가짜를 의심해요. |
| 똑같은 양손 | 진짜 왼손과 오른손은 거울처럼 서로 반대 모양이에요. 두 손이 완전히 똑같으면 이상한 거예요. |
| 몸의 개수 오류 | 귀가 3개, 다리가 5개… AI는 몸의 개수를 자주 틀려요. 하나하나 세어 보면 들통나요. |
| 앞뒤가 안 맞는 말 | '오전에 문을 닫고 아침 일찍 문을 열어요'처럼 앞뒤가 모순되는 글은 AI가 그럴듯한 문장을 이어 붙이다 실수한 거예요. |
| 광고처럼 매끈한 말 | 같은 말을 자꾸 반복하거나, 진짜 경험 없이 '지금 바로!' 하며 광고처럼 끝나는 글을 조심해요. |
