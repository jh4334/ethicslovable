## 여행 5개 역 설명

- 📡 **수집**: 방금 누른 것들이 하나하나 기록됐어요. 앱은 우리가 무엇을 눌렀는지 조용히 다 적어 둬요.
- 🗄️ **저장**: 기록된 조각들은 데이터 창고에 표처럼 차곡차곡 정리돼요. 언제, 무엇을, 어떻게 했는지까지요.
- 🤖 **분석**: 이제 AI가 태그를 하나하나 세어 봐요. 많이 누른 태그일수록 '관심 있다'고 판단해 순위를 매겨요.
- 👤 **프로필**: 센 결과를 바탕으로 AI가 '이런 사람일 것 같아'라는 추측 카드를 만들어요. 진짜 내가 아니라 추측이에요.
- 📢 **맞춤 광고**: 그 추측 카드에 맞춰 광고를 골라 보내요. 광고가 나를 잘 아는 것처럼 느껴지는 이유예요.

## AI 추측 프로필 문구

- 동물: 동물을 좋아하고 마음이 따뜻한 사람인 것 같아요.
- 게임: 게임을 좋아하고 도전을 즐기는 사람인 것 같아요.
- 요리: 요리를 좋아하고 맛있는 걸 나누고 싶어 하는 사람인 것 같아요.
- 운동: 운동을 좋아하고 몸으로 노는 걸 즐기는 사람인 것 같아요.
- 과학: 과학을 좋아하고 호기심이 많은 사람인 것 같아요.
- 패션: 꾸미기를 좋아하고 유행에 밝은 사람인 것 같아요.
- 꿀팁: 생활 꿀팁을 차곡차곡 모으는 야무진 사람인 것 같아요.
- 귀여움: 귀여운 것을 보면 그냥 지나치지 못하는 사람인 것 같아요.
- 간식: 간식 이야기에 눈이 반짝이는 사람인 것 같아요.
- 만들기: 무언가를 직접 만드는 걸 좋아하는 사람인 것 같아요.
- 유행: 요즘 유행을 빠르게 챙기는 사람인 것 같아요.
- default: 여러 가지에 두루 관심이 많은 사람인 것 같아요.

## 데이터 지키기 시나리오 4개

### 시나리오 1: 새로 깐 앱이 물어봐요. "위치 정보를 항상 허용할까요?"
- ▫️ 항상 허용을 누른다 → 앱을 안 쓸 때도 내가 어디에 있는지 계속 기록돼요. 데이터는 꼭 필요한 만큼만 주는 게 좋아요.
- ✅ '앱을 쓸 때만 허용'을 고른다 → 훌륭해요! 필요한 순간에만 데이터를 주는 것, 그게 바로 데이터 여행자의 똑똑한 선택이에요.
- ▫️ 귀찮으니 아무 버튼이나 빨리 누른다 → 잠깐! 묻는 창을 읽지 않고 누르면 내 데이터가 어디로 가는지 나도 모르게 돼요. 한 번만 천천히 읽어 봐요.

### 시나리오 2: 누리피드 설정에서 '검색 기록 관리' 메뉴를 발견했어요. 내가 검색한 말이 전부 남아 있네요!
- ✅ 가끔 들어가서 오래된 기록을 지운다 → 맞아요! 검색 기록은 내가 확인하고 지울 수 있어요. 기록을 관리하면 나에 대한 추측도 내가 조절할 수 있어요.
- ▫️ 그런 메뉴는 못 본 척 다시는 안 연다 → 아쉬워요. 기록이 쌓일수록 나에 대한 추측도 쌓여요. 어떤 기록이 남는지 가끔 들여다보는 습관이 필요해요.
- ▫️ 기록이 쌓이든 말든 신경 쓰지 않는다 → 내 기록은 내 것이에요. 아무도 대신 지켜 주지 않으니, 주인인 내가 가끔 확인해 줘야 해요.

### 시나리오 3: "무료 선물 100% 당첨!" 광고를 눌렀더니 이름, 전화번호, 학교 이름을 적으라고 해요.
- ▫️ 선물이 갖고 싶으니 얼른 적는다 → 위험해요! '무료'는 미끼일 수 있어요. 개인정보를 가져가려는 낚시 광고에 소중한 정보를 주면 안 돼요.
- ✅ 적지 않고 창을 닫은 뒤 어른과 이야기한다 → 완벽해요! 개인정보를 요구하는 공짜 이벤트는 일단 멈추고 어른과 확인하는 게 최고의 방패예요.
- ▫️ 내 이름 대신 친구 이름을 적는다 → 안 돼요! 친구의 개인정보도 나만큼 소중해요. 남의 정보를 대신 적는 건 친구를 위험하게 만드는 일이에요.

### 시나리오 4: 광고 구석에 조그맣게 '이 광고가 왜 보일까요?' 버튼이 있어요.
- ✅ 눌러서 광고가 나에게 온 이유를 확인해 본다 → 바로 그거예요! 많은 앱에는 광고가 온 이유를 알려 주는 버튼이 있어요. 확인하면 내 데이터가 어떻게 쓰였는지 알 수 있어요.
- ▫️ 광고는 원래 그냥 오는 거라며 넘긴다 → 이제는 알잖아요! 맞춤 광고는 그냥 오지 않아요. 내가 남긴 데이터 조각을 따라 온 거예요.
- ▫️ 물건이 신기하니 광고부터 눌러 구경한다 → 광고를 누르는 것도 새로운 데이터 조각이 돼요. 누르기 전에 '왜 나에게 왔지?' 한 번 생각해 봐요.
