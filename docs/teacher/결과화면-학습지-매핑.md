# 결과 화면 ↔ 학습지 매핑 안내

각 차시 게임의 **결과 화면에 뜨는 수치·등급·칭호**가 개인 학습지 **② 게임 중 기록하기**의 어느 칸으로 들어가는지 정리한 대조표입니다. 사전에 게임을 해 보지 못한 선생님도, 학생이 화면의 어떤 값을 학습지로 옮겨 적어야 하는지 바로 안내할 수 있습니다.

> 사용법: 게임이 끝난 직후 결과 화면을 열어 둔 채, 아래 '결과 화면 표기'에 해당하는 값을 찾아 '학습지 ② 칸'에 옮겨 적게 하세요. 표기 문구는 실제 화면 렌더링을 근거로 했으며, `{ }`는 학생마다 달라지는 값입니다. 등급·칭호 원문은 `src/content/<게임>.json`에 있습니다.

---

## 1차시 · 알고리즘 설계자 (feed-algorithm)
결과 화면에 **점수·등급은 없습니다.** 엔딩과 성향, 근무 일수를 옮겨 적습니다.

| 결과 화면 표기 | → 학습지-1차시 ② 칸 |
|---|---|
| "7일 근무 완료!" / "시뮬레이션 종료" · "{n}일차까지 운영" | 며칠까지 버텼나요? (7일 완주 ⭕/❌) |
| 네 수치(🔥조회수·🛡️안전·💰수익·🤝신뢰)의 마지막 값 | 마지막 조회수/안전/수익/신뢰 각 칸 |
| 엔딩 이모지+제목, "요원 평가 리포트"의 플레이 성향(📈 성장 몰입형 / 🛡️ 안전 중시형 / 🎯 균형형) | 내가 받은 결과(엔딩 이름 또는 요원 칭호) |

> 성향 3종은 등급이 아니라 플레이 스타일 라벨입니다("어느 게 더 높다"가 아님).

## 2차시 · 필터버블 탐지기 (filter-bubble)
| 결과 화면 표기 | → 학습지-2차시 ② 칸 |
|---|---|
| 필터버블 위험도 게이지의 **{점수}점** | 내 필터버블 위험도 __/100점 |
| 게이지 3단계 레벨 라벨 **안전 / 주의 / 위험** | 위험도 단계 (○표) |
| "나의 알고리즘 성향" 아래 **성향 칭호**(예: 골고루 탐험가) | 내 칭호 |
| 분야별 선택 분포 상위 순서 | 좋아한 분야 1·2·3위 / 외면한 분야 |

> 저장 이미지 파일명은 `필터버블-탐지기-결과.png`. 1차·2차 위험도를 각각 기록해 비교합니다.

## 3차시 · 추천 요정 훈련소 (social-insight)
결과 화면에 **등급 체계는 없습니다.**

| 결과 화면 표기 | → 학습지-3차시 ② 칸 |
|---|---|
| "{난이도} 난이도"(쉬움/보통/어려움) | 내가 고른 난이도 (○표) |
| 맞힌 라운드 수 | 맞힌 라운드 __/10 |
| 대형 **{점수}점** | 최종 점수 |
| "최대 {maxCombo}콤보" (콤보 문구 ✨/💫/⚡/🔥) | 최고 콤보 칭찬 (○표) |

## 4차시 · 알고리즘 연구소장 (trend-tycoon)
| 결과 화면 표기 | → 학습지-4차시 ② 칸 |
|---|---|
| 대문자 **등급 S / A / B / C / D** + 등급 메시지 | 최종 등급 (○표) |
| **{총점}점**(totalScore) | 최종 점수 |

> 미션별 슬라이더 방향(②의 미션 표)은 게임 진행 중 직접 관찰해 기록하는 부분으로, 결과 화면 값이 아닙니다.

## 5차시 · 데이터 편식쟁이 AI (data-bias)
등급 없음. **정확도(%)** 를 시험 차수별로 옮겨 적습니다.

| 결과 화면 표기 | → 학습지-5차시 ② 칸 |
|---|---|
| "아기봇 정확도 {accuracy}%" (1차 시험) | 1차 시험 아기봇 정확도 __% |
| 2차 시험 정확도, "{r1}% → {r2}%" 비교 | 2차 시험 아기봇 정확도 __% |
| "왜 틀렸을까요?" 화면의 틀린 문제·까닭 | 틀린 문제(동물)·틀린 까닭 |

## 6차시 · 완벽한 가짜 (deepfake)
| 결과 화면 표기 | → 학습지-6차시 ② 칸 |
|---|---|
| 👀 눈으로 **{eyeScore}/{총 눈시험 라운드}** | 1부 눈 시험 __/5 |
| 🧰 검증으로 **{verifyScore}/{총 사건수}** | 2부 검증 수사 __/4 사건 |
| "{caseScore}점"(최종 점수) | 최종 점수 |
| 수사대 등급: 🐣 견습 수사관 / 🔍 수사대 요원 / 🕵️ 베테랑 수사관 / 🏅 명예 수사대장 | 내 수사대 등급 (○표) |

> '우리 반 눈 시험 평균'은 칠판 집계값으로, 화면 값이 아닙니다.

## 7차시 · 누리봇 사실 검증단 (fact-check)
| 결과 화면 표기 | → 학습지-7차시 ② 칸 |
|---|---|
| "{correctCount}/{totalRounds}"(정확히 검증한 라운드) | 정확히 검증한 라운드 __/8 |
| 검증 요원 등급: 🌱 새싹 / 🔎 성실 / 🛡️ 믿음직 / 🏅 특급 검증 요원 | 내 검증 요원 등급 (○표) |

## 8차시 · 내 데이터의 여행 (data-trail)
등급명 없음. **데이터 방패 개수**와 프로필 카드 문구를 옮깁니다.

| 결과 화면 표기 | → 학습지-8차시 ② 칸 |
|---|---|
| "AI가 추측한 나" 프로필 카드의 관심사 상위 | AI가 계산한 내 관심사 1·2위 |
| 프로필 카드 문구 | 'AI가 추측한 나' 카드 문구(그대로) |
| 🛡️ "내가 모은 데이터 방패 {shields}개 / {총 방패수}개" | 내가 모은 데이터 방패 __/4개 |

## 9차시 · 멈출 수 없는 화면 (short-form)
| 결과 화면 표기 | → 학습지-9차시 ② 칸 |
|---|---|
| 조사 수치칸 "본 영상 {n}개" | 내가 본 영상 __개 |
| "가상 시청 시간"(영상 1개=30초 환산) | 가상 시청 시간 __분 |
| "시간 짐작 오차" | 시간 퀴즈 짐작 오차 __분 |
| "멈추기 챌린지" 결과 | 멈추기 챌린지 (○표) |
| 지킴이 등급: 🌱 새싹 / 🥉 동빛 / 🥈 은빛 / 🥇 금빛 화면 지킴이 | 내 지킴이 등급 (○표) |

## 10차시 · 뽑기 상자의 비밀 (gacha-box)
| 결과 화면 표기 | → 학습지-10차시 ② 칸 |
|---|---|
| 등급별 뽑은 개수(공개 확률표와 함께) | 등급별 내가 뽑은 개수 |
| 🎁 "뽑은 횟수 {n}회" / 💰 "쓴 코인" | 뽑은 횟수 __번 / 쓴 코인 __코인 |
| 😫 "아쉬움 연출 {n}번" | 아쉬움 연출("전설…?!") __번 |
| 확률 퀴즈(정답 ⭕ / 다시 도전 ❌) | 확률 퀴즈 (○표) |
| 지킴이 등급: 🌱 새싹 / 🛡️ 베테랑 / 🏅 전설의 지킴이 (3단계) | (학습지 ②에는 등급칸 없음 — 참고) |

## 11차시 · 검색 결과 탐정 (search-detective)
| 결과 화면 표기 | → 학습지-11차시 ② 칸 |
|---|---|
| "{correctCount}/{totalRounds}"(해결한 미션) | 해결한 미션 __/6 |
| "{score}점"(최종 점수) | 최종 점수 |
| 탐정 등급: 🌱 새내기 / 🧢 견습 / 🔎 베테랑 / 🕵️ 전설의 검색 탐정 | 내 탐정 등급 (○표) |
| 단서 도감 "{모은수}/{전체}" | (③ 단서 도감 이름 옮기기와 연계) |

## 12차시 · 단톡방을 지켜라 (chat-guard)
| 결과 화면 표기 | → 학습지-12차시 ② 칸 |
|---|---|
| "지킴이 배지 {badges}/{total}" | 내가 받은 지킴이 배지 __/5개 |
| 등급: 🌱 자라나는 / 🌟 듬직한 / 💚 빛나는 단톡방 지킴이 (3단계) | 내 칭호 (○표) |

## 13차시 · 누리봇에게 말해도 될까? (ai-privacy)
| 결과 화면 표기 | → 학습지-13차시 ② 칸 |
|---|---|
| "안전 점수 {correct}/{total}"(+미터) | 내가 바르게 판단한 메시지 __/10개 |
| 위험 정보 도감 "{모은수}/{전체}" | 위험 정보 도감에 모은 정보 __/7종 |
| 안전 요원 등급: 🧩 연습 중인 / 🔹 새내기 / 🔷 믿음직한 / 🛡️ 특급 안전 요원 | 내 요원 등급 (○표) |

## 14차시 · 모두의 AI (ai-fair)
심사 화면(FinalScreen)과 결과 화면(ResultScreen) 두 곳에 값이 나옵니다.

| 결과 화면 표기 | → 학습지-14차시 ② 칸 |
|---|---|
| ⚖️ 포용 미터 "쓸 수 있는 사람 {enabled}/{total}" (결과 화면 "포용 {enabled}/{total}") | 누리봇을 쓸 수 있게 된 친구 __/6명 |
| "시험한 횟수 {rounds}" | 내가 시험한 횟수 __번 |
| 설계자 등급: 🔰 견습 / 🌱 새내기 / 🌟 훌륭한 / 🏅 으뜸 포용 설계자 | 내 설계자 등급 (○표) |

> 심사 화면의 "카드 선택 {picked}/3"은 ④ '개선 3개 남기기' 활동과 연결됩니다.

## 15차시 · 누가 만들었게? (ai-copyright)
| 결과 화면 표기 | → 학습지-15차시 ② 칸 |
|---|---|
| "{score}점"(책임 점수) | 책임 점수 __점 |
| "{correctCount}/{totalRound1}"(바르게 판단한 상황) | 바르게 판단한 상황 __/6개 |
| 심판 등급: 🌱 견습 / 📖 배우는 / ⚖️ 믿음직한 / 🏅 으뜸 창작 심판 | 내 심판 등급 (○표) |
| 책임 원칙 도감 "{모은수}/{전체}" | (③ 책임 원칙 이름 옮기기와 연계) |

## 16차시 · AI와 함께 크는 나 (ai-grow)
| 결과 화면 표기 | → 학습지-16차시 ② 칸 |
|---|---|
| 🌱 "쌓은 지식 {totalSkill}/{maxSkill}" | 내가 쌓은 지식 카드 __개 |
| 🔍 "지식으로 잡은 오류 {errorsCaught}/{totalMissions}" | 지식으로 잡은 오류 __개 |
| 성장 등급: 💧 이제 막 물 주기 / 🌱 돋아나는 새싹 / 🌿 쑥쑥 크는 나무 / 🌳 AI를 잘 다루는 큰나무 | 내 성장 등급 (○표) |

---

### 등급 체계 한눈에
- **등급 4단계**(낮음→높음): 6·7·9·13·14·15·16차시
- **등급 S~D**: 4차시
- **등급 3단계**: 10·12차시
- **등급 없음**(수치·성향·순위만): 1(성향 3종)·2(위험도+안전/주의/위험)·3(점수+순위)·5(정확도%)·8(방패 개수)차시

> 학습지 ②의 등급 '○표' 칸은 결과 화면 등급명과 일대일로 대응하니, 화면의 등급 이모지·이름을 그대로 찾아 표시하게 하면 됩니다.
