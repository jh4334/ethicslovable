모둠 이름: ______________  모둠원: ______ ______ ______ ______  날짜: ___월 ___일

> 검색 탐정 여섯 명이 아니라, 우리 모둠 네 명이 **합동 수사대**가 되는 시간이에요!
> 각자 모은 단서를 합치면 도감이 더 빨리 완성되고, 검색 결과에 숨은 함정들을

### 활동 1 · 이야기 나누기 (모둠 토의) 🗣️

**모둠원끼리 각자 해결한 미션을 이야기하며 아래 발문을 나눠요.**

1. '강아지 사료 추천' 미션에서 **맨 위 두 결과**는 무엇이었나요? (둘 다 무슨 칩이 붙어 있었나요?)
2. '키 크는 법'과 '감기에 좋은 음식' 미션의 정답은 왜 둘 다 **보건소 누리집**이었나요?
3. 협찬 문구("○○로부터 제품을 받아 작성했어요")를 찾은 사람? 그건 본문 **어디에, 어떤 크기로** 숨어 있었나요?

**모둠 단서 도감 합치기 — 6종을 다 모았는지 서로 채워 줘요.**

| 📢 광고 표시 | 🏛️ 공식 출처 | 🎁 협찬 문구 | 🗓️ 오래된 날짜 | 💥 과장 제목 | ❓ 근거 없음 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |

### 활동 2 · 협력 미션 — 검색 함정 분류 카드 나누기 🗂️

**아래 '검색 결과 카드' 8장을 오려서(또는 번호를 적어서), 모둠원이 함께 4개의 함정 바구니에 나눠 담아요.** 하나의 카드가 두 바구니에 들어갈 수도 있어요 — 그럴 땐 왜 그런지 이야기해 봐요.

**분류할 검색 결과 카드 8장 (게임 속 실제 결과)**

| 번호 | 검색 결과 제목 |
|:---:|---|
| ① | "튼튼사료 전 제품 최대 반값! 오늘만 이 가격" — 옆에 '광고' 칩 |
| ② | "이 글은 든든펫으로부터 사료를 무료로 받아 작성했어요" (후기 맨 끝 작은 글씨) |
| ③ | "충격! 이것만 먹으면 한 달에 5센티가 큰다?!" |
| ④ | "어린이는 15,000원이에요" — 2021년에 달린 문답 답변 |
| ⑤ | "무조건 굶어야 빨리 나아요. 저는 항상 그렇게 해요" — 감기 문답 답변 |
| ⑥ | "누리랜드 입장권 2,000원 할인 행사" — 옆에 '광고' 칩 |
| ⑦ | "충격! 전설의 수호자, 곧 서비스 종료된다?!" — 2년 전 소문 글 |
| ⑧ | "새 수호자 미리 해 봤어요… 이 글은 게임 회사로부터 이용권을 받아 작성했어요" |

**네 가지 함정 바구니 — 카드 번호를 나눠 담아요.**

| 🟥 광고 (돈 내고 올라온 자리) | 🎁 협찬 (공짜로 받고 쓴 후기) | 💥 과장 (부풀린 낚시 제목) | 🗓️ 오래된 정보 (날짜 지난 글) |
|:---:|:---:|:---:|:---:|
| | | | |

### 활동 3 · 함께 만들기 — 믿을 수 있는 검색 3단계 안내판 🪧

**모둠이 함께, 다른 반 친구도 보고 따라 할 수 있는 '믿을 수 있는 검색 3단계' 안내판을 만들어요.** 게임의 '검색 3단계 습관'을 큼직한 3칸으로 정리해요.

```
┌──────────────┬──────────────┬──────────────┐
│   1단계       │   2단계       │   3단계       │
│              │              │              │
│ '(     )'    │ (     )      │ 결과를        │
│ 글자부터      │ 쓴 글인지     │ (   )개 이상  │
│ 찾아요        │ 확인해요      │ 비교해요      │
│              │ (출처·협찬·   │              │
│ (그림)        │  날짜 확인)   │ (그림)        │
└──────────────┴──────────────┴──────────────┘
```

우리 안내판 아래에 붙일 한마디: "맨 위라고 (&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;) 좋은 정보가 아니에요!"

<small>**교사용 지도 팁** · 활동 2 분류의 예: 광고=①⑥, 협찬=②⑧, 과장=③⑦, 오래된 정보=④⑦ — 카드 하나가 여러 함정에 걸치는 경우(⑦은 과장+오래된 정보)가 좋은 토론거리이므로 '정답 한 칸'을 강요하지 않는다. · "광고는 나쁜 것"이 아니라 "광고를 광고인 줄 모르고 믿는 것"이 문제라는 균형을 지키고, "협찬 후기는 전부 거짓"이 아니라 "좋은 점만 말하기 쉬우니 한 번 더 의심"으로 정리한다. · 건강 정보(③⑤)는 잘못 따라 하면 몸이 위험할 수 있는 안전 교육 접점이므로, 공식 출처·어른·병원과 확인하는 습관으로 반드시 연결한다.</small>
