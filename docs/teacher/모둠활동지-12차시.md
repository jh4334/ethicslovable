## 12차시 · 단톡방을 지켜라 💬 — 우리 반 상황극 & 디지털 시민 선언 (대장정 마무리)

모둠 이름: ______________  모둠원: ______ ______ ______ ______  날짜: ___월 ___일

> 12주 퀘스트의 **마지막 시간**이에요! 오늘은 단톡방 사건을 우리 모둠이 직접 몸으로
> 연기해 보고, 12주 여정 전체를 담은 **'우리 반 디지털 시민 선언'**을 함께 만들어요.
> 마지막에는 온 반이 모여 선언에 서명해요.

---

### 활동 1 · 이야기 나누기 (모둠 토의) 🗣️

**모둠원끼리 조심스럽게, 아래 발문으로 이야기해요.**

1. 우리 반(또는 다른 단톡방)에서 **진짜 있었던 비슷한 일**을 이야기해 봐요. — *단, 특정 친구 이름은 말하지 않기! "어느 단톡방에서나 있을 수 있는 일"로만 이야기해요.*
2. 게임의 다섯 사건(소문 · 수상한 링크 · 저격 · 사진 · 밤 알림) 중, 우리 모둠이 **가장 자주 겪는 일**은 무엇일까요?
3. '조용히 지켜보기 · 나만 안 누르기 · 자리 피하기'는 왜 **'절반의 성공'**일까요? 지킴이와 방관자는 무엇이 다를까요?

**모둠이 고른, 우리에게 가장 필요한 사건 하나:** ☐ 소문 ☐ 링크 ☐ 저격 ☐ 사진 ☐ 밤 알림

---

### 활동 2 · 협력 미션 — 우리 반 단톡방 상황극 🎭

**활동 1에서 고른 사건 하나로 짧은 역할극을 만들어요.** 모둠원이 배역을 나누고, 아래 대본의 빈칸을 채워 완성해요. 게임 속 '슬기로운 선택'이 나오도록 만드는 것이 목표예요.

**배역 정하기** (게임 속 인물 이름을 그대로 써도 좋아요: 도윤 🐯 · 서아 🐰 · 준호 ⚽ · 민재 🎮 · 유나 🎹 · 하람 🦊 · 지우 🌼)

| 배역 | 맡은 모둠원 | 이 배역의 역할 |
|---|---|---|
| 사건을 일으키는 사람 | | 소문/링크/저격 등을 시작해요 |
| 휩쓸리는 친구 | | 처음엔 같이 반응해요 |
| **지킴이(슬기로운 선택)** | | 흐름을 멈추는 한마디를 해요 |
| 상처받거나 곤란한 친구 | | 마음을 표현해요 |

**대본 채우기**

- (사건 시작) ______: "&nbsp;__________________________________________________"
- (휩쓸림) ______: "&nbsp;______________________________________________________"
- **(지킴이의 한마디)** ______: "&nbsp;_________________________________________________"
- (반응이 바뀜) ______: "&nbsp;____________________________________________________"

> 💡 지킴이 대사 힌트 — 소문: "그거 직접 본 사람 있어?" / 링크: "비밀번호 치는 건 가짜 사이트 같아, 어른께 알리자" / 저격: "장난이어도 듣는 사람은 속상해, 그만하자" / 사진: "하람이한테 먼저 물어봐야지" / 밤 알림: "지금은 잘 시간이야, 내일 아침에 이어서 하자"

### 활동 3 · 함께 만들기 — 우리 반 디지털 시민 선언 🏅 (12주 여정의 마무리)

**이건 단톡방 약속만이 아니에요.** 1부(알고리즘) · 2부(인공지능) · 3부(슬기로운 누리 생활)까지 **열두 개 퀘스트에서 배운 것 전부**를 담은, 우리 반의 큰 선언이에요. 각 부에서 배운 것을 한 줄씩 뽑아 '우리는 이렇게 살겠다'는 다짐으로 완성해요.

```
┌───────────────────────────────────────────────────────┐
│            🏅 우리 반 디지털 시민 선언 🏅               │
│                                                       │
│  우리는 12주 동안 누리마을 지킴이로 배웠습니다.         │
│                                                       │
│  하나. (1부 · 알고리즘) 추천이 보여 주는 것만 믿지 않고, │
│        ______________________________________________ │
│                                                       │
│  둘. (2부 · 인공지능) AI의 말과 가짜 콘텐츠는 눈이 아니라 │
│        ______________________________________________ │
│                                                       │
│  셋. (3부 · 시간·소비·검색·단톡방) 멈추기 어렵고 사고 싶고 │
│      믿고 싶어지는 건 설계 때문임을 알고, 우리는          │
│        ______________________________________________ │
│                                                       │
│  넷. 단톡방에서 힘든 친구를 모른 척하지 않고,            │
│        ______________________________________________ │
│                                                       │
│           우리는 진짜 세상의 디지털 지킴이입니다!        │
└───────────────────────────────────────────────────────┘
```

> 힌트 — 하나: "출처를 확인하고 골고루 본다" / 둘: "절차(멈춤·출처·원본·공식)로 확인한다" / 셋: "계산하고 비교한 다음 스스로 정한다" / 넷: "먼저 말을 건다"
