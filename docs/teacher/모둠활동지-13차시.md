### 활동 1 · 이야기 나누기 (모둠 토의) 🗣️

**모둠원끼리 돌아가며 아래 발문으로 이야기해요.**

1. 게임에서 '멈춰!'로 막아야 했던 메시지 중, **가장 헷갈렸던 것**은 무엇이었나요? (위험 정보 도감: 이름 🪪 · 연락처 📞 · 주소·학교 🏫 · 비밀번호 🔑 · 사진 🖼️ · 남의 정보 🧑‍🤝‍🧑 · 비밀 이야기 🤫)
2. 누리봇에게 **실수로 개인정보를 보냈을 때**, 게임 2부에서 배운 대응 순서는 무엇이었나요? *(힌트: 대화 지우기 → 어른께 알리기 → 비밀번호는 곧바로 바꾸기)*
3. '말해도 되는 것'(화산·수학·독후감 고치는 방법)과 '말하면 안 되는 것'은 무엇이 다른가요? 한마디로 정하면?

**우리 모둠의 결론 한 줄:** 말하면 안 되는 것은 바로 ______________________________ 가 담긴 메시지예요.

### 활동 2 · 협력 미션 🧩

**① 위험 상황 카드 분류 — '보내기 OK ✅ / 멈춰! ✋'**

| 메시지 카드 | 우리 판정 (✅ / ✋) | 멈춰라면, 무슨 정보? |

| ㉰ "독후감을 더 잘 고치는 방법을 알려 줘." | | |
| ㉱ "우리 집 전화번호는 010-○○○○이야." | | |
| ㉲ "나는 ○○초 6학년 3반이야. 소개글 써 줘." | | |
