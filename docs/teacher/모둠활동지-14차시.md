# 미디어 리터러시 퀘스트 · 모둠 협력 활동지 ⑭

## 14차시 · 모두의 AI ⚖️ — 우리 모둠 누리봇 포용 설계실 회의

모둠 이름: ______________  모둠원: ______ ______ ______ ______  날짜: ___월 ___일

> 각자 누리봇 포용 설계자가 되어, 여섯 명 모두가 쓸 수 있는 누리봇을 만들고 왔어요.
> 이제 모둠으로 모여, **우리 반·우리 학교에서 AI·디지털 기기를 쓰기 어려운 친구**는
> 없는지 함께 찾고, 그 장벽을 없앨 개선 아이디어를 설계해요.
> "모두가 쓰는 AI를 만들려면?"을 우리 모둠 힘으로 풀어 봐요.

### 활동 1 · 이야기 나누기 (모둠 토의) 🗣️

**모둠원끼리 돌아가며 아래 발문으로 이야기해요.**

1. 게임에서 기본 누리봇으로 **처음엔 여섯 명 중 몇 명만** 잘 썼나요? 왜 그랬을까요? *(힌트: 설계자가 '평균적인 한 사람'만 떠올려서요.)*
2. 못 쓰던 네 친구의 장벽(🗣️사투리 · 🌏서툰 한국어 · 👀소리 없는 화면 · 📶느린 인터넷)을 이야기해 봐요. 이건 **그 친구가 부족해서**일까요, **누리봇 설계가 놓쳐서**일까요?
3. '표준어만 더 잘하기 📚' 카드는 왜 **함정 카드**였나요? *(똑똑해지긴 하지만, 못 쓰던 친구는 여전히 못 써요.)*

**우리 모둠의 결론 한 줄:** 사람을 바꾼 게 아니라, ______________________________ 를 바꿔서 모두가 쓸 수 있게 됐어요.

### 활동 2 · 협력 미션 🧩

**① 브레인스토밍 — 우리 반·우리 학교 포용 지도**

게임 밖 진짜 세상으로 눈을 돌려요. **우리 반이나 우리 학교에서 AI·디지털 기기를 쓰기 어려울 수 있는 친구**를 모둠이 함께 떠올려 적어요. *(특정 친구 이름은 쓰지 않고 "○○한 친구"로만 적어요.)*

| 어떤 친구가 어려울까요? | 어떤 장벽 때문일까요? | 이건 누구 책임? (사람 vs 설계) |
|---|---|---|
| | | ☐ 사람 ☐ 설계 |
| | | ☐ 사람 ☐ 설계 |
| | | ☐ 사람 ☐ 설계 |
| | | ☐ 사람 ☐ 설계 |

> 💡 게임에서 배웠듯, 못 돕는 건 늘 **누리봇(설계)의 책임**이에요. '설계'에 ✅가 많아지도록 이야기해 봐요.

**② 개선 아이디어 설계 — 장벽을 없애는 카드 만들기**

위에서 찾은 장벽을 없앨 개선 아이디어를 설계해요. 게임처럼, **한 개선이 여러 장벽을 한꺼번에** 돕기도 해요!

| 우리 개선 카드 이름 | 어떤 장벽을 없애나요? | 이 개선으로 누가 쓸 수 있게 되나요? |

### 활동 3 · 함께 만들기 ⚖️ — '모두가 쓰는 누리봇' 설계 카드

우리 모둠이 설계한 개선을 모아, **'모두가 쓰는 누리봇' 설계 카드**를 완성해요. 게임의 '모두를 위한 AI 3원칙'을 우리 모둠 말로 채워요.

```
┌─────────────────────────────────────────────┐
│   ⚖️ 모두가 쓰는 누리봇 설계 카드            │
│                                             │
│   우리가 달 개선 카드:                       │
│    · ______________________________________  │
│    · ______________________________________  │
│    · ______________________________________  │
│                                             │
│   🚫 차별 줄이기: ___________________________ │
│   🌈 다양성 존중: ___________________________ │
│   🤝 모두 접근:   ___________________________ │
│                                             │
│   한 문장 다짐: 똑똑한 AI보다              │
│    ________________________ AI가 좋은 AI예요. │
│                                             │
│   포용 설계자 모둠: ______________________    │
└─────────────────────────────────────────────┘
```

---

<small>**교사용 지도 팁** · 이 차시의 핵심 프레이밍은 ai-fair.json과 같다 — 사투리·다문화·장애·농산어촌은 '사람이 부족한 것'이 아니라 'AI 설계가 놓친 것'이다. 활동 2①에서 '그 친구가 못 해서'라는 발화가 나오면 "누리봇 설계가 그 친구를 깜빡한 거예요"로 되돌린다. · 동정하는 말투 대신 존중하는 상태 서술("아직 안 배워서예요")을 쓰도록 안내한다. · 게임에서 최소 3장(사투리·여러 나라 말 배우기 + 소리/큰 글자 중 1장 + 가벼운 버전)으로 6/6이 됨을 상기시키며, '한 개선이 여러 장벽을 함께 없앤다'는 포용 설계의 원리를 강조한다. · 3원칙은 세부원칙 4(차별 줄이기)·5(다양성 존중)·6(모두 접근)에 정렬한다.</small>
