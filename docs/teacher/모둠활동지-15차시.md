모둠 이름: ______________  모둠원: ______ ______ ______ ______  날짜: ___월 ___일

> 각자 누리마을 '창작 심판'이 되어, AI로 만든 작품을 쓸 때 옳은지 판단하고 왔어요.
> 이제 모둠으로 모여, **애매한 저작권·정직 상황**을 놓고 '괜찮아요 · 안 돼요 ·
> 밝히면 돼요'로 토론·판정하고 근거를 대요. 그리고 **우리 모둠의
> 'AI 창작 책임 규칙'**을 만들어요.

### 활동 1 · 이야기 나누기 (모둠 토의) 🗣️

**모둠원끼리 돌아가며 아래 발문으로 이야기해요.**

1. 게임에서 **'밝히면 돼요'가 정답**이었던 상황과 **'안 돼요'가 정답**이었던 상황은 무엇이 달랐나요? *(힌트: 규칙을 확인하고 정직하게 밝혔나 vs 숨기거나 남의 것을 베꼈나.)*
2. 채원이처럼 AI에게 **'아이디어만' 묻고 직접 그린 것**은 왜 '괜찮아요'였을까요?
3. 작품을 냈는데 "남의 그림이랑 너무 비슷하다"는 말을 들으면 어떻게 해야 하나요? *(힌트: 멈추고(내리고) → 만든 과정 기록 챙겨 → 선생님께 알리기.)*

**우리 모둠의 결론 한 줄:** AI로 만들어도 ______________ · ______________ · ______________ 는 꼭 지켜야 해요.

---

### 활동 2 · 협력 미션 ⚖️ — 모둠 창작 심판대

아래 애매한 상황을 모둠이 함께 토론해 **'괜찮아요 🟢 · 안 돼요 🔴 · 밝히면 돼요 🟡'** 중 하나로 판정하고, 왜 그렇게 판정했는지 **근거**를 적어요. *(책임 원칙: 출처 밝히기 📌 · 남의 것 존중 🎨 · 정직하게 출품 🏅 · 목적·범위 지키기 🎯)*

| 상황 | 우리 판정 | 근거 (어떤 원칙?) |
|---|:---:|---|
| ㉮ AI로 만든 그림을 대회에 내면서 '내가 처음부터 직접 그렸어요'라고 적었어요. | 🟢·🔴·🟡 | |
| ㉯ 대회 규칙이 'AI 써도 됨'이라, 'AI 도움을 받아 만들었어요'라고 밝히고 냈어요. | 🟢·🔴·🟡 | |
| ㉰ 유명 작가 그림체를 AI로 똑같이 따라 만들어서 돈 받고 팔았어요. | 🟢·🔴·🟡 | |
| ㉱ AI가 써 준 독후감을 한 글자도 안 고치고 내 숙제로 냈어요. | 🟢·🔴·🟡 | |
| ㉲ 교과서 삽화를 AI로 바꿔, '우리 반' 수업용으로만 쓰고 출처를 밝혔어요. | 🟢·🔴·🟡 | |
| ㉳ AI에겐 '어떤 주제로 그릴까?' 아이디어만 묻고, 그림·글은 내가 직접 했어요. | 🟢·🔴·🟡 | |

**➡ 모둠 판정이 갈리면, "이걸로 누가 손해를 볼까?", "규칙을 확인했나?", "정직하게 밝혔나?"를 물으며 합의해요.**

### 활동 3 · 함께 만들기 📝 — 우리 모둠 'AI 창작 책임 규칙'

모둠 토론을 바탕으로, AI로 창작할 때 지킬 **'AI 창작 책임 규칙' 카드**를 완성해요. 게임의 'AI 창작 3약속'을 우리 모둠 말로 채워요.

```
┌─────────────────────────────────────────────┐
│   📝 우리 모둠 AI 창작 책임 규칙             │
│                                             │
│   📌 밝혀요:                                 │
│    AI를 썼다면 ____________________________  │
│                                             │
│   🎨 존중해요:                               │
│    남이 만든 작품은 ______________________   │
│                                             │
│   🏅 정직해요:                               │
│    대회·숙제엔 __________________________     │
│    만큼만 내 것이라고 해요.                   │
│                                             │
│   🎯 지켜요: 정해진 목적과 범위(예: 우리 반   │
│    수업용)에서만 써요.                        │
│                                             │
│   문제가 생기면? 멈추고 → ________________    │
│    → 선생님께 알려요.                         │
│                                             │
│   창작 심판 모둠: ________________________    │
└─────────────────────────────────────────────┘
```
