# 미디어 리터러시 퀘스트 모둠 협력 활동지 ①

## 1차시 · 알고리즘 설계자 🧙 — 우리 모둠의 누리피드 설계실 회의

모둠 이름: ______  모둠원: ______ ______ ______ ______  날짜: ___

> 여러분은 각자 7일 동안 누리피드 알고리즘 설계실에서 근무하고 온 요원이에요.
> 이제 모둠으로 모여, 서로 다른 근무 결과를 맞대어 보고 **우리 모둠만의 착한 알고리즘 규칙**을 함께 만들어요.

### 활동 1 · 이야기 나누기 (모둠 토의)

동그랗게 모여 앉아, 아래 질문을 하나씩 돌아가며 이야기해요.

1. 우리 모둠은 각자 며칠까지 살아남았나요? 7일을 완주한 사람이 있나요?
2. 어떤 수치가 0이나 100에 닿아서 근무가 끝났나요? (🔥 조회수 / 🛡️ 안전 / 💰 수익 / 🤝 신뢰) 어떤 엔딩이었나요? (예: '디지털 좀비 사태', '재미없는 앱', '거짓말쟁이 낙인')
3. '위험한 챌린지'나 '저격 영상' 같은 카드에서, 나와 옆 친구의 선택이 서로 달랐던 적이 있나요? 왜 달랐을까요?

**모둠 의견을 한 칸에 모아 적어요.**

| 우리 모둠이 함께 찾은 점 | |
|---|---|
| 우리 모둠에서 가장 많이 나온 엔딩 이유(어떤 수치 때문에?) | |
| 같은 카드인데 선택이 갈렸던 카드와 그 까닭 | |

### 활동 3 · 함께 만들기 (모둠 산출물)

**우리 모둠의 '착한 알고리즘 규칙 3가지' 포스터를 만들어요.** 게임에서 느꼈듯이 모두에게 완벽하게 착한 알고리즘은 어려워요. 그래도 우리 모둠이 누리피드를 운영한다면 꼭 지킬 규칙 3가지를 정해요. 규칙마다 '이 규칙을 지키면 어떤 수치가 손해를 볼 수도 있는지'까지 솔직하게 적어요.

```
│                                             │
│   모둠 이름: ____________________              │
│                                             │
│   규칙 1. ______________________________     │
│      (감수할 손해: ____________________ )      │
│                                             │
│   규칙 2. ______________________________     │

│                                             │

```

<small>**교사용 진행 팁** · 모둠은 4명 내외로, 요원 유형(성장·안전·균형)이 골고루 섞이도록 편성하면 활동 1·2의 대화가 풍부해진다. · 시간 배분은 활동 1(7분)·활동 2(12분)·활동 3(15분)·활동 4(6분)를 권장하며, 활동 2의 ㉱ 순위 정하기에서 토의가 길어지므로 타이머를 활용한다. · '착한 규칙=거절만 하는 규칙'으로 흐르지 않게 한다. 게임 설계처럼 거절에도 손해(이용자 이탈·수익 감소)가 따르므로, 규칙마다 '감수할 손해' 칸을 반드시 채우게 하여 '완벽한 정답은 없고 균형이 있을 뿐'임을 체감시킨다.</small>
