# 미디어 리터러시 퀘스트 모둠 협력 활동지 ②

## 2차시 · 필터버블 탐지기 🫧 — 우리 모둠 성향 분석 회의

모둠 이름: ______  모둠원: ______ ______ ______ ______  날짜: ___

> 각자 성향 분석 실험실에서 카드를 10번 골라, 자신의 **필터버블 위험도**를 확인하고 왔어요.
> 이제 모둠의 결과를 한자리에 모아, 우리 모둠은 무엇을 즐겨 보고 무엇을 놓치고 있는지 함께 살펴봐요.

---

### 활동 1 · 이야기 나누기 (모둠 토의)

1. 우리 모둠의 필터버블 위험도 점수를 모아 봐요 — 누가 제일 높았고, 누가 제일 낮았나요?
2. 각자 어떤 칭호가 나왔나요? (예: "게임에 푹 빠진 게임 달인", "맛에 진심인 꼬마 미식가", "골고루 탐험가") 우리 모둠에 같은 칭호가 나온 사람이 있나요?
3. "충격! 몽실이의 숨겨진 비밀", "충격! 급식에서 이게 나왔다?!" 같은 **빨간 점(자극적인) 카드**에 손이 갔던 사람? 어떤 말이 우리를 끌어당겼나요?

**모둠 의견을 한 칸에 모아 적어요.**

| 우리 모둠이 함께 찾은 점 | |
|---|---|
| 우리 모둠에서 위험도가 가장 높았던 사람과 그 사람의 1위 분야 | |
| 자극적인 제목에 손이 가게 만든 낱말(예: '충격!', '?!', '비밀') | |

### 활동 3 · 함께 만들기 (모둠 산출물)

**우리 모둠의 '정보 편식 탈출 식단표'를 만들어요.** 분야를 음식이라고 생각해 봐요. 우리 모둠이 즐겨 먹는(즐겨 보는) 분야는 '이미 충분한 음식', 미션 ㉰에서 찾은 놓친 분야는 '더 챙겨 먹을 음식'이에요. 균형 잡힌 하루 식단표를 짜요.

| 끼니 | 어떤 분야를 볼까요? | 구체적인 볼거리 (예: '지식' 분야의 "우주는 얼마나 클까?") |
|---|---|---|
| 🌅 아침 (편하게 즐기는 분야) | | |
| ☀️ 점심 (새로 챙길 분야 1) | | |
| 🌙 저녁 (새로 챙길 분야 2) | | |
| 🍎 간식 (모둠이 다 함께 놓친 분야) | | |

우리 모둠 식단표 이름: ____________________

<small>**교사용 진행 팁** · 모둠 편성 시 위험도 점수가 비슷한 학생끼리 몰리지 않도록 섞으면 막대그래프의 편차가 드러나 토의가 살아난다. · 시간 배분은 활동 1(6분)·활동 2(13분, 그래프에 색연필 필요)·활동 3(14분)·활동 4(5분)를 권장한다. · 위험도가 높게 나온 학생을 놀리지 않도록, 게임 문구대로 "확실한 취향은 멋진 것, 다만 편식은 조심"이라는 관점을 미리 못박고, 활동의 목표는 개인 점수 비교가 아니라 '우리 모둠이 함께 놓친 분야 발견'임을 강조한다.</small>
