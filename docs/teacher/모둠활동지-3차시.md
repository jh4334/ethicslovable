# 미디어 리터러시 퀘스트 모둠 협력 활동지 ③

## 3차시 · 추천 요정 훈련소 🔮 — 우리 모둠 추천 요정 회의

모둠 이름: ______  모둠원: ______ ______ ______ ______  날짜: ___

> 각자 추천 요정이 되어, 친구가 좋아요를 누른 게시물을 보고 다음 게시물을 골라 주는 훈련을 하고 왔어요.
> 이제 모둠으로 모여, **우리가 알고리즘이라면 어떻게 추천할지** 규칙을 함께 정해요.

---

### 활동 1 · 이야기 나누기 (모둠 토의)

1. 각자 어떤 난이도(🌱 쉬움 / ⚡ 보통 / 🔥 어려움)로 몇 점을 받았나요? 우리 모둠 최고 점수는 누구였나요?
2. 가장 높이 이어 간 콤보 칭찬은 무엇이었나요? (✨ 좋았어요! / 💫 굉장해요! / ⚡ 불이 붙었어요! / 🔥 막을 수 없어요!)
3. '패션/꾸미기 · 여행/나들이 · 게임/과학 · 반려동물' 네 관심사 중, **함정 게시물에 걸려 헷갈렸던** 관심사가 있었나요? 어떻게 알아챘나요?

**모둠 의견을 한 칸에 모아 적어요.**

| 우리 모둠이 함께 찾은 점 | |
|---|---|
| 우리 모둠 최고 점수·최고 콤보 | |
| 함정 게시물을 알아챈 우리만의 단서 (예: 태그#, 올린 계정 이름) | |

---

### 활동 2 · 협력 미션 (모둠 데이터 활동)

**미션 ㉮ · 우리 모둠 추천 성적표를 모아요.**

| 모둠원 이름 | 난이도 | 점수 | 최고 콤보 | 함정에 걸린 횟수 |
|---|:---:|:---:|:---:|:---:|
| | | | | |
| | | | | |
| | | | | |
| | | | | |

우리 모둠 점수 순위 1위: ____________  ·  함정에 가장 적게 걸린 사람: ____________

**미션 ㉯ · "우리가 알고리즘이라면" 추천 규칙 합의하기.** 추천 요정으로 일해 본 경험을 모아, 모둠이 다 함께 지킬 추천 규칙을 정해요. 아래 세 가지를 회의로 채워요.

| 우리 모둠 추천 규칙 | 모둠 합의 내용 |
|---|---|
| ① 다음 게시물을 고를 때 **꼭 볼 단서**는? (제목·태그#·계정·사진 중) | |
| ② **함정을 피하는 방법**은? (겉모습이 비슷해도 관심사가 다른 게시물 거르기) | |
| ③ 같은 관심사만 계속 추천하면 친구는 어떻게 될까요? (2차시에 배운 낱말로) | |

---

### 활동 3 · 함께 만들기 (모둠 산출물)

**우리 모둠의 '추천 요정 캠페인 문구'를 만들어요.** 게임 결과 화면에는 "추천 알고리즘은 우리가 좋아요를 누른 것과 비슷한 게시물만 계속 보여 줘요. 새로운 이야기를 만나고 싶다면 스스로 찾아보는 습관이 필요해요!"라는 말이 나와요. 이 뜻을 살려, 친구들이 '추천만 기다리지 않도록' 이끄는 짧은 캠페인 문구와 그림을 만들어요.

```
┌─────────────────────────────────────────────┐
│   🔮 우리 모둠 추천 요정 캠페인                     │
│                                             │
│   한 줄 구호(제목):                             │
│   ____________________________________      │
│                                             │
│   설명 문구(1~2문장):                          │
│   ____________________________________      │
│   ____________________________________      │
│                                             │
│   캠페인 그림/마스코트 (여기에 그려요)               │
│                                             │
│                                             │
│                                             │
└─────────────────────────────────────────────┘
```

<small>**교사용 진행 팁** · 모둠은 난이도 도전 성향이 다른 학생을 섞으면 활동 1의 대화가 다양해진다(쉬움만 한 학생과 어려움에 도전한 학생의 경험 대비). · 시간 배분은 활동 1(6분)·활동 2(13분)·활동 3(15분)·활동 4(6분)를 권장한다. · 활동 2 ㉯에서 '점수를 잘 받는 규칙'과 '친구에게 이로운 추천'이 다를 수 있음을 짚어 준다 — 관심사만 계속 맞히면 점수는 높지만 친구의 피드는 필터버블에 갇힌다는 3차시 도달점을, ③번 칸의 답('필터버블/정보 편식')을 통해 모둠 스스로 발견하게 한다.</small>
