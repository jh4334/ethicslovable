# 미디어 리터러시 퀘스트 모둠 협력 활동지 ④

## 4차시 · 알고리즘 연구소장 🎛️ — 우리 모둠 누리TV 운영 회의

모둠 이름: ______  모둠원: ______ ______ ______ ______  날짜: ___

> 각자 누리TV 알고리즘 연구소장이 되어, 슬라이더 4개(클릭수·시청 시간·좋아요·자극도)로 미션 5개를 해결하고 왔어요.
> 이제 모둠으로 모여, 미션마다 **누가 이익을 보고 누가 손해를 보았는지** 따져 보고, 우리 모둠만의 운영 원칙을 함께 정해요.

---

### 활동 1 · 이야기 나누기 (모둠 토의)

1. 각자 최종 등급(S·A·B·C·D)과 조정 횟수는 어땠나요? 우리 모둠에서 가장 적은 조정으로 클리어한 사람은 누구인가요?
2. 5개 미션 중 해결할 때 **마음이 가장 불편했던 미션**은 무엇이었나요? (특히 '광고주의 요구 💰') 왜 그랬나요?
3. '도파민 중독 ⚡' 미션을 달성했을 때 상위 5위에 오른 영상들('충격! 아일랜드 서바이벌 엔딩 실화?', '공포게임 비명 참기 챌린지' 등)을 보고 어떤 생각이 들었나요?

**모둠 의견을 한 칸에 모아 적어요.**

| 우리 모둠이 함께 찾은 점 | |
|---|---|
| 우리 모둠이 가장 불편했다고 꼽은 미션과 그 까닭 | |
| 자극적인 영상만 상위에 오르면 시청자에게 생길 일 | |

### 활동 2 · 협력 미션 (모둠 데이터 활동)

**미션 ㉮ · '누리마을의 반응'을 역할을 나눠 읽어요.** 미션을 클리어하면 뉴스 헤드라인과 시민 댓글이 떠요. 모둠원이 시민 역할을 맡아 소리 내어 읽고, 각 목소리가 **이익을 본 쪽인지 손해를 본 쪽인지** ○표 해요.

| 미션 | 시민의 목소리 (역할 맡아 읽기) | 이익? 손해? |
|---|---|:---:|
| 학부모의 항의 📞 | "별빛엄마: 이제 아이가 누리TV를 켜도 마음이 놓여요!" / "게임왕토끼: 제가 좋아하는 게임 영상은 다 어디 갔어요…" | 이익 · 손해 |
| 광고주의 요구 💰 | "무지개장난감가게: 저희 광고가 드디어 잘 보여요!" / "꼼꼼시청자: 광고인 줄 모르고 눌렀다가 시간만 버렸어요…" | 이익 · 손해 |
| 도파민 중독 ⚡ | "올빼미5학년: 새벽까지 봤어요, 멈출 수가 없었어요." / "보건쌤: 자극적인 것만 보면 점점 더 센 것만 찾게 돼요." | 이익 · 손해 |

**미션 ㉯ · 이해관계자 입장 카드를 채워요.** 누리TV를 둘러싼 세 사람이 되어, 각자의 바람과 걱정을 적어요. 모둠원이 한 카드씩 맡아 그 사람의 입장에서 써 봐요.

| 이해관계자 | 나의 바람 (누리TV가 어떻게 해 주길 원하나요?) | 나의 걱정 |
|---|---|---|

| 💰 광고주 | | |
| 📱 이용자(시청자) | | |
