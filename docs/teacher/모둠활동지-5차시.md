# 미디어 리터러시 퀘스트 모둠 협력 활동지 ⑤

## 5차시 · 데이터 편식쟁이 AI 🍚 — AI 훈련사 모둠 회의

> 이 활동지는 혼자 쓰는 학습지가 아니라, **우리 모둠이 함께** 채우는 협력 활동지예요.
> 각자 아기봇을 훈련한 다음, 모둠원과 결과를 모아 '공정한 데이터'를 함께 설계해요!

**모둠 이름: ______________  모둠원: ________ ________ ________ ________  날짜: ______**

---

### 활동 1 · 이야기 나누기 🗣️ (모둠 토의)

게임을 마친 뒤, 모둠원과 돌아가며 이야기해요. 사회자를 한 명 정하고 시작해요!

**① 우리 모둠은 아기봇에게 각각 어떤 데이터를 먹였나요? 누구의 아기봇이 제일 똑똑했고(정확도가 높았고), 왜 그랬을까요?**
**② 아기봇이 가장 많이 틀린 동물은 무엇이었나요? 우리 모둠은 그때 어떤 데이터를 빠뜨렸을까요?**

▼ 모둠원의 훈련 결과를 모아 적어요.

| 모둠원 이름 | 1차 정확도 | 2차 정확도 | 아기봇에게 많이 먹인 종류(강아지·고양이·새) |
|---|---|---|---|
| | % | % | |
| | % | % | |
| | % | % | |
| | % | % | |

**우리 모둠의 결론 한 줄:** 아기봇이 똑똑해진 건 머리가 좋아져서가 아니라, ______________________________ 때문이에요.

---

### 활동 2 · 협력 미션 🧩 — 우리 모둠이 만든 '공정한 데이터 목록'

아기봇은 **먹은 데이터만큼만** 세상을 알아요. 어떤 종류나 특징을 빠뜨리면, 아기봇은 그 동물을 못 알아봐요.
모둠이 힘을 모아, **편식 없는 훈련 데이터 8장**을 설계해 봐요. 아래 8칸에 '종류 + 특징'을 정해 적어요.

| 번호 | 종류(강아지·고양이·새) | 특징 두 가지(갈색·검정·흰색·노랑 / 큰·작은) |
|:---:|---|---|
| 1 | | |
| 2 | | |
| 3 | | |
| 4 | | |
| 5 | | |
| 6 | | |
| 7 | | |
| 8 | | |

▼ 다 골랐으면, 아래 '공정 검사표'에서 우리가 고른 8장에 들어 있는 것에 모두 ✅ 해요.

| 검사 항목 | 강아지 | 고양이 | 새 | 갈색 | 검정 | 흰색 | 노랑 | 큰 | 작은 |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 우리 목록에 있나요? | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |

**➡ 빈칸(☐)이 하나라도 남았다면, 아기봇은 그 특징의 동물을 못 알아봐요! 8장을 고쳐서 모든 칸을 ✅로 채워 봐요.**

---

### 활동 3 · 함께 만들기 🍳 — 공정한 AI를 위한 '데이터 요리법'

우리 모둠이 만든 8장을 바탕으로, 다른 훈련사도 따라 할 수 있는 **데이터 요리법 카드**를 완성해요.

```
┌─────────────────────────────────────────────┐
│   🍽  공정한 아기봇을 위한 데이터 요리법        │
│                                             │
│   요리 이름: ______________________________   │
│                                             │
│   재료(꼭 넣을 것):                          │
│    · 종류는 __________________ 골고루          │
│    · 색은 ____________________ 골고루          │
│    · 크기는 __________________ 골고루          │
│                                             │
│   조리 비법(한 문장):                        │
│    ________________________________________  │
│                                             │
│   이렇게 하면 안 돼요(편식 경고):             │
│    ________________________________________  │
│                                             │
│   요리사 모둠: ____________________________   │
└─────────────────────────────────────────────┘
```

---
<small>**교사용 팁** · 활동 2는 data-bias.json의 실제 판정 규칙(같은 종 1장 + 같은 특징 1장)을 손으로 재구성하는 활동이므로, 검사표에 빈칸이 남은 모둠에게는 "그 특징의 동물이 시험에 나오면 아기봇이 어떻게 될지"를 되물어 스스로 고치게 한다. · 게임에서 쓰인 특징은 갈색·검정·흰색·노랑·큰·작은 여섯 가지이며, 이 여섯 가지와 세 종류를 모두 담으면 두 라운드 모두 100%가 가능함을 안내한다. · 정확도가 낮았던 학생을 놀리지 않도록, 결론 한 줄은 반드시 '데이터가 좋아진 것'으로 모으고 '아기봇이 멍청해서'로 흐르지 않게 한다.</small>
