### 활동 2 · 협력 미션 📊 — 우리 반 눈 시험 결과 집계표

혼자 보면 "운이 나빴나 봐"로 끝나지만, **반 전체를 모으면 진짜 증거**가 보여요!

**(가) 반 전체 점수 집계** — 선생님이 "0개인 사람?"부터 손 들기를 하면, 모둠이 사람 수를 세어 적어요.

| 눈 시험 점수 | 0개 | 1개 | 2개 | 3개 | 4개 | 5개 | 합계 |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 우리 반 사람 수 | | | | | | | 명 |

**(나) 막대그래프로 그리기** — 점수마다 사람 수만큼 칸을 아래에서 위로 색칠해요.

```
사람수
 10 │ ☐   ☐   ☐   ☐   ☐   ☐
  8 │ ☐   ☐   ☐   ☐   ☐   ☐
  6 │ ☐   ☐   ☐   ☐   ☐   ☐
  4 │ ☐   ☐   ☐   ☐   ☐   ☐
  2 │ ☐   ☐   ☐   ☐   ☐   ☐
    └──────────────────────────
      0점  1점  2점  3점  4점  5점
```

**(다) 평균과 비교하기**
- 우리 반 눈 시험 평균: 약 **______ 개**
- 동전을 던져서 찍어도 평균은 **2.5개** — 우리 반 평균과 비교하면? (○표) 〔 비슷해요 · 훨씬 높아요 · 훨씬 낮아요 〕
- 모둠 결론: 우리 반이 동전 던지기와 비슷하다는 건, ________________________________________ 라는 뜻이에요.

**(라) 모둠 수사 회의록** — 사건 하나를 골라, 검증 도구 4개를 순서대로 적용해 결론을 내려요.
(사건 고르기: 은하수 다섯 해체 · 누리마을 초등학교 폐교 · 몽실이 간식 기부 · 요리왕 뚝딱 기프트 코드)

### 활동 3 · 함께 만들기 🛡️ — 가짜를 이기는 '4단계 검증 포스터'

우리 반 뒤에 붙일 포스터를 모둠이 함께 만들어요. 네 칸에 도구 이름과 '이럴 때 이렇게!'를 적어요.

```
┌───────────────────┬───────────────────┐
│  🛑 (         )    │  🔎 (         )    │
│  이렇게 해요:      │  이렇게 해요:      │
│  _______________  │  _______________  │
├───────────────────┼───────────────────┤
│  🌐 (         )    │  📢 (         )    │
│  이렇게 해요:      │  이렇게 해요:      │
│  _______________  │  _______________  │
└───────────────────┴───────────────────┘
     우리 모둠 표어: "믿을 건 눈이 아니라 ________!"
```

---
<small>**교사용 팁** · 눈 시험에서 4~5점을 받은 학생이 "난 눈으로 가릴 수 있다"고 일반화하지 않도록, 반드시 **반 평균(2.5개 근처)** 을 함께 확인시킨다 — 다섯 문제를 다 찍어도 여섯 명 중 한 명꼴로 4점 이상이 나오므로 개인 고득점은 확률상 우연임을 그래프로 보여 준다. · 집계는 "0개인 사람?"부터 손 들기로 1분이면 끝나며, 막대그래프가 2·3점 부근에 몰리는 모양이 곧 '눈으로는 못 가린다'의 증거다. · 수사 회의록에서 진짜였던 '몽실이 간식 기부'를 고른 모둠에는 "검증 절차는 가짜만 잡는 게 아니라 진짜도 안심하고 믿게 해 준다"는 결론까지 이끌어 준다.</small>
