### 활동 3 · 함께 만들기 📜 — AI에게 물을 때 지킬 '우리 모둠의 약속'

누리봇 같은 AI를 잘 부리려면 규칙이 필요해요. 모둠이 토의해서 약속 3가지를 정하고, 확인 방법도 적어요.

```
┌─────────────────────────────────────────────┐
│   🤝  AI에게 물을 때 우리 모둠이 지킬 약속     │
│                                             │
│   약속 1. ___________________________________ │
│   약속 2. ___________________________________ │
│   약속 3. ___________________________________ │
│                                             │
│   우리가 확인할 때 쓰는 자료(예: 백과·책·     │
│   공식 누리집·선생님):                        │
│    ________________________________________  │
│                                             │
│   우리 모둠 한마디: "의심이 아니라 __________!" │
└─────────────────────────────────────────────┘
```
