# 미디어 리터러시 퀘스트 모둠 협력 활동지 ⑧

## 8차시 · 내 데이터의 여행 🧳 — 데이터 여행자 합동 임무

> 혼자 쓰는 학습지와 달리, 이 활동지는 **우리 모둠이 함께** 채워요.
> 각자의 '데이터 그림자'를 모아 공통점을 찾고, 우리 반 데이터 지킴이 수칙을 만들어요!

**모둠 이름: ______________  모둠원: ________ ________ ________ ________  날짜: ______**

---

### 활동 1 · 이야기 나누기 🗣️ (모둠 토의)

**① 'AI가 추측한 나' 카드는 진짜 나와 얼마나 닮았나요? AI가 틀리게 추측한 부분이 있었나요?**
**② 광고가 나에게 온 이유("○○ 태그를 몇 번 눌렀기 때문")를 확인했을 때 어떤 기분이었나요?**
**③ "무료 선물 100% 당첨!" 낚시 광고를 만난 사람? 다른 맞춤 광고와 무엇이 달랐나요?**

---

### 활동 2 · 협력 미션 👥 — 우리 모둠의 '데이터 그림자' 모으기

각자의 프로필 카드(데이터 그림자)를 한자리에 모아, **공통점과 다른 점**을 찾아봐요.

| 모둠원 이름 | AI가 계산한 관심사 1위 | 관심사 2위 | 모은 데이터 방패 (__/4) |
|---|---|---|:---:|
| | | | /4 |
| | | | /4 |
| | | | /4 |
| | | | /4 |

▼ 모아 놓고 살펴봐요.
- 우리 모둠에서 **가장 많이 나온 관심사**: ______________
- 똑같은 게임을 했는데도 **관심사가 다 다른 까닭**은? ________________________________________
- 모둠 발견: 프로필 카드가 서로 다른 건, 각자 남긴 ______________ 이(가) 다르기 때문이에요.
- 이 카드를 '진짜 나'가 아니라 **'그림자'** 라고 부르는 까닭: ______________________________________

---

### 활동 3 · 함께 만들기 🛡️ — 우리 모둠 '데이터 지킴이 수칙 포스터'

내 데이터가 어디로 가는지 배웠으니, 이제 **지키는 방법**을 모둠이 함께 정해 포스터로 만들어요.
(힌트: 위치 정보는 '앱을 쓸 때만 허용' · 검색 기록 가끔 지우기 · '이 광고가 왜 보일까요?' 눌러 보기 · 무료 이벤트에 개인정보 적지 않기)

```
┌─────────────────────────────────────────────┐
│   🛡  우리 모둠 데이터 지킴이 수칙            │
│                                             │
│   하나. ____________________________________ │
│   둘.   ____________________________________ │
│   셋.   ____________________________________ │
│                                             │
│   위험 신호! 이런 걸 만나면 멈춰요:           │
│    ________________________________________  │
│                                             │
│   우리 모둠 다짐: "데이터를 남기는 건 나쁜    │
│   게 아니에요. 어디로 가는지 ______, 내가    │
│   ______ 게 중요해요."                       │
└─────────────────────────────────────────────┘
```

---

### 활동 4 · 발표 준비 📣

- 발표 담당 모둠원: ______________
- 우리 모둠의 한 줄 발표문:
  "우리 모둠은 관심사가 다 달랐지만, 데이터를 지키는 첫 번째 수칙은 똑같이 ______________________________ 로 정했어요!"

---
<small>**교사용 팁** · 활동 2는 각자의 프로필 카드(누리피드에서 누른 태그로 만들어진 추측)를 모아 비교하는 활동이므로, "같은 게임인데 왜 카드가 다른가"를 통해 '프로필은 내가 남긴 데이터 조각의 결과'임을 스스로 발견하게 한다. · 방패 개수가 적은 학생을 놀리지 않도록, 결과 화면 문구("괜찮아요, 오늘 처음 배운걸요")의 관점을 유지하고 아쉬웠던 선택을 함께 되짚는다. · 포스터가 "앱을 쓰면 안 된다"는 공포로 흐르지 않게, 핵심 메시지는 '금지'가 아니라 '어디로 가는지 알고 내가 정하기'(데이터 주권)임을 분명히 한다.</small>
