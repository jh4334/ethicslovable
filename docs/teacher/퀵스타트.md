# 신규 교사용 퀵스타트 — 내일 40분, 바로 굴리기

처음 이 자료를 받은 선생님이 **사전 지식 없이 다음 시간에 바로** 수업할 수 있도록 만든 한 장짜리 안내입니다. 게임 설치도, 로그인도, 계정도 없습니다. 브라우저 하나면 됩니다.

> 이 프로그램은 초등 5~6학년용 미디어·AI 리터러시 게임 16개(4부 16차시)입니다. 게임 속 SNS(누리피드)·동영상 앱(누리TV)·AI 캐릭터(아기봇·누리봇)·인물·게시물은 모두 교육용으로 창작한 가상 세계관 '누리마을'의 콘텐츠이며, 실존 브랜드·인물은 나오지 않습니다.

## 1. 실행 3줄 (셋 중 하나만 고르면 됩니다)

| 상황 | 이렇게 하세요 |
|---|---|
| **온라인** (인터넷 되는 교실) | 배포된 **URL에 접속**하면 끝. (예: `https://jh4334.github.io/ethicslovable/`) 학생 기기에서 주소만 열면 바로 게임 목록이 뜹니다. |
| **오프라인** (인터넷 없는 PC실) | `dist-offline/index.html` 파일 **하나를 USB·메신저로 옮겨 더블클릭**. 파일 안에 게임이 통째로 들어 있어 인터넷 없이 실행됩니다. |
| **콘텐츠 수정** (게시물·카드 문구 바꾸기) | 게임 텍스트는 전부 `data/*.json`(웹 배포본은 `dist/data/*.json`)에 있습니다. **메모장으로 열어** 고치면 웹 배포본은 재빌드 없이 바로 반영됩니다. (오프라인 단일 파일은 수정 후 `npm run build:offline` 재실행 필요) |

시작 화면에서 **차시(게임)를 눌러 들어가면 되고, 뒤로 나오면 다시 목록**입니다. 학생은 자기 차시 게임 하나만 하면 됩니다.

## 2. 16차시 운영표

**핵심 구조부터 잡으세요.**

- **한 차시 = 40분 1교시 = 게임(10~15분) + 개인 학습지.** 게임을 먼저 하고, 그 결과를 학습지에 옮겨 적으며 토의·성찰합니다.
- **모둠활동지는 그 뒤에 이어지는 별도 40분(선택)** 입니다. 시간이 없으면 안 해도 되고, 두 시간을 확보하면 게임 차시 → 모둠 차시로 이어 운영합니다.
- 즉 **16차시 = 게임 16 + 모둠활동 16(선택)** 입니다. 필수는 게임+학습지 16시간, 모둠활동 16시간은 학교 사정에 따라 더하는 확장분입니다.

한 차시 40분은 대개 **도입 5분 · 전개(게임+기록) 25분 · 정리(토의·다짐) 10분** 흐름입니다.

| 차시 | 게임 | 학습 주제 | 게임 시간(대략) |
|---|---|---|---|
| **1부 · 알고리즘의 비밀** ||||
| 1 | 🧙 알고리즘 설계자 | 추천 알고리즘의 기준과 상업적 동기 | 약 15분 (재도전 1~2회 권장) |
| 2 | 🫧 필터버블 탐지기 | 내 선택이 만드는 정보 편식 | 약 8분씩 2회(솔직히→골고루) |
| 3 | 🔮 추천 요정 훈련소 | 추천의 원리와 사회적 영향 | 3~4분/회, 2~3회 (총 15분) |
| 4 | 🎛️ 알고리즘 연구소장 | 플랫폼 운영자의 수익·책임 딜레마 | 약 15분 |
| **2부 · 인공지능과 살아가기** ||||
| 5 | 🍚 데이터 편식쟁이 AI | AI 학습과 데이터 편향 | 1차 7분, 2차까지 약 15분 |
| 6 | 🎭 완벽한 가짜 | AI 생성물 검증(눈이 아닌 절차) | 눈시험 5분 + 검증 10분 |
| 7 | ✅ 누리봇 사실 검증단 | AI 환각과 사실 검증 | 8라운드 약 12분 |
| 8 | 🧳 내 데이터의 여행 | 개인정보와 맞춤 광고 | 약 15~18분 |
| **3부 · 슬기로운 누리 생활** ||||
| 9 | 📱 멈출 수 없는 화면 | 숏폼과 시간 감각 | 약 12분 |
| 10 | 🎁 뽑기 상자의 비밀 | 확률형 아이템과 소비 | 뽑기 5분, 계산·해부 포함 15분 |
| 11 | 🔎 검색 결과 탐정 | 검색 리터러시(광고·협찬·출처) | 6라운드 약 15분 |
| 12 | 💬 단톡방을 지켜라 | 메신저 예절·디지털 시민성 | 약 18분 (3부 중 가장 김) |
| **4부 · AI와 바르게 쓰기** ||||
| 13 | 🛡️ 누리봇에게 말해도 될까? | AI와 개인정보(안전) | 약 13분 |
| 14 | ⚖️ 모두의 AI | AI와 공정·포용(공정) | 약 12~15분 |
| 15 | 📝 누가 만들었게? | AI와 저작권(책임) | 약 12~15분 |
| 16 | 🌱 AI와 함께 크는 나 | 지식×AI(성장) | 약 15~18분 |

> 게임 오버·재도전이 있는 차시(1·3·5차시 등)에서는 "게임 오버도 실패가 아니라 엔딩·기록 모으기"라고 미리 안내하면 학생 좌절이 줄어듭니다.

## 3. 차시별 준비물 한 줄 표 (현장 함정 포함)

기본 준비물은 **학생 기기(1인 1기기 권장, 2인 1기기도 좋음) + 개인 학습지 인쇄(학생 수만큼) + 필기구**입니다. 아래는 차시마다 특별히 챙길 것과 자주 걸리는 함정만 뽑았습니다.

| 차시 | 특별 준비물·현장 함정 |
|---|---|
| 1 | 학습지 1부/인. 게임 오버가 잦으니 **재도전 시간 확보**. "승인=나쁨/거절=착함" 아님을 미리 정리. |
| 2 | 결과 화면 **이미지 저장**을 씁니다 → '결과 이미지 저장' 버튼을 누르면 `필터버블-탐지기-결과.png`가 내려받아집니다. **태블릿은 저장 위치를 미리 확인**해 두고, 학습지에 붙이거나 학급 게시판에 활용. 1차·2차 2회 플레이 안내. |
| 3 | 게임 시작 때 **이름을 입력**합니다(명예의 전당 기록용). **반드시 '별명' 사용 안내.** 이 기록은 그 브라우저에만 남으니, **공용 PC실이면 수업 후 브라우저 데이터(localStorage) 삭제**로 정리. |
| 4 | 슬라이더 조작 게임. "자극도 슬라이더는 **마이너스(음수)로도 내려간다**"를 모르는 학생이 가장 많으니 먼저 안내. |
| 5 | 1차는 일부러 편식을 경험시키는 설계 → **1차 전에 "골고루 고르세요"라고 알려 주지 않기.** 2차에서 개선. |
| 6 | 1부 눈 시험 뒤 **반 전체 점수 집계(칠판)** 활동이 효과적 → 눈 시험 결과 화면에서 잠깐 멈추기. |
| 7 | 자료 서랍을 안 열고 감으로 찍는 학생 주의. 누리마을 정보 라운드는 **자료 없이는 못 맞히도록** 설계돼 있음. |
| 8 | '데이터 수집'은 **게임 안 흉내일 뿐, 저장·전송 없음**(시작 화면에도 안내). 낚시 광고 "무료 선물 100% 당첨!" 상황이 핵심. |
| 9 | 화면에 **시계가 일부러 없음**(시간 감각 흐리기 체험). '멈추기 챌린지' 결과를 학습지에 기록. |
| 10 | 확률·용돈 **계산 활동**이 본론 → 뽑기에서 시간 끌지 않기. 계산이 있으니 필요시 연습장. |
| 11 | 라운드마다 해설·단서 카드가 뜸 → **해설 읽기까지가 한 라운드**임을 안내(빨리 넘기지 않기). |
| 12 | 3부 중 플레이가 가장 김(약 18분) → **도입을 짧게**, 정리의 '단톡방 약속 카드' 활동에 시간 확보. |
| 13 | 개인정보 예시(이름·전화번호·비밀번호 등)는 **모두 가상 인물 예시**. 학생이 자기 정보를 입력하는 일은 없음. |
| 14 | 틀린 개선 카드는 그 손님에게 다시 못 쓰게 잠김 → "틀려도 괜찮다, 설계는 원래 고치는 것" 안내로 좌절 방지. |
| 15 | 판정보다 **해설(왜 그런지) 읽기에 시간 쓰기**. '정답 맞히기'가 목적이 아님. |
| 16 | 한 미션은 지식을 충분히 쌓고, 한 미션은 일부러 건너뛰게 하면 '아는 만큼 보인다'를 한 사람이 직접 대비 체험. |

> **인쇄 부수**: 개인 학습지는 **학생 1인 1부**, 모둠활동지(선택)는 **모둠당 1부**입니다. 16차시 전체를 미리 인쇄하려면 `docs/teacher/학습지-인쇄용.html`(A4 16쪽)·`모둠활동지-인쇄용.html`을 브라우저에서 열고 Ctrl+P로 뽑으면 됩니다.

## 4. 학습지 배부·회수 표준 절차

학습지는 **①→④ 순서**로 되어 있어 수업 흐름과 그대로 맞물립니다. 이대로만 하면 됩니다.

1. **도입에 배부** → 곧바로 **① '게임 전 예상하기'를 먼저 쓰게** 합니다. (게임을 하기 전에 예상을 적어 두는 것이 이 자료의 핵심 장치입니다.)
2. **전개(게임 중~직후)** → 게임 결과 화면을 보고 **② '게임 중 기록하기'** 칸에 수치·등급을 옮겨 적습니다. (어느 수치를 어디에 옮기는지는 `결과화면-학습지-매핑.md` 참고)
3. **정리** → **③ 생각하기 · ④ 실천 다짐**까지 채웁니다.
4. **④까지 다 채운 학습지를 걷어** 마무리합니다.

한 문장 요약: **도입에 배부하고 ①부터 쓰기 → 정리에 ④까지 채워 걷기.**

## 5. 2인 1기기 운영법

기기가 부족해도 괜찮습니다. 오히려 짝 토의가 활발해집니다.

- **역할 나누기**: 한 명은 **조작**(카드 넘기기·버튼 누르기), 한 명은 **기록**(학습지에 결과 적기·화면 보고 상의).
- **라운드(또는 미션·에피소드)마다 역할 교대** → 두 학생 모두 조작과 기록을 경험합니다.
- 선택 전 **"이거 왜 골랐어?"를 짝에게 말하고 누르기** 규칙을 주면 판단 근거를 말로 꺼내게 됩니다.

### 접속이 안 될 때(교사 시연 대안)

기기 문제·인터넷 장애로 학생이 못 들어가면, **교사 화면 하나를 TV·빔에 띄워 함께 진행**합니다.

- 교사가 조작하고, 선택은 **학생들에게 손들기·거수로 물어** 정합니다("승인? 거절?").
- 결과 화면 수치를 **다 같이 보며 학습지 ②에 옮겨 적게** 하면, 개별 플레이 없이도 토의·성찰 흐름은 그대로 살아 있습니다.
- 오프라인 단일 파일(`dist-offline/index.html`)을 교사 PC에 미리 받아 두면, 인터넷이 끊겨도 시연이 가능합니다.
