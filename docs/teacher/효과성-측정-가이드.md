# 미디어 리터러시 퀘스트 — 효과성 측정 가이드 (교사·연구자용)

이 문서는 「미디어 리터러시 퀘스트」(초등 5~6학년, 4부 16차시) 프로그램의 교육 효과를 **개인정보 수집 없이** 측정·집계·해석하도록 돕는 실무 안내서예요. 이미 제공하는 [`사전사후-검사지.md`](사전사후-검사지.md)를 '어떻게 쓰고, 어떻게 계산하고, 어떻게 읽을지'에 초점을 맞췄어요. 검사지 문항 자체와 채점 기준표는 그 문서를 그대로 따르고, 여기서는 **교실에서의 운영 절차와 집계 방법**을 다뤄요.

> **개인정보 수집 없음 — 이 가이드의 대원칙**
> 이 프로그램과 검사는 학생의 이름·연락처 등 개인을 식별할 수 있는 정보를 **일절 수집하지 않아요.** 검사지는 이름 대신 **익명 번호**로만 관리하고, 결과는 **학급 단위 집단 통계**로만 정리해요. 게임 진행 기록도 서버가 아니라 사용 중인 브라우저(localStorage)에만 남아요. 아래 모든 절차는 이 원칙 위에서 설계했고, 문서 곳곳에서 다시 짚을게요.

---

## 1. 측정 설계

### 1.1 기본 설계 — 단일집단 사전·사후 비교

가장 간단하고 초등 현장에 맞는 설계는 **한 학급을 대상으로 수업 전(사전)과 수업 후(사후)에 같은 검사를 실시해 변화를 보는 것**이에요.

| 시점 | 언제 | 무엇을 |
|---|---|---|
| 사전 검사 | **1차시 시작 전**(같은 날 도입 전 또는 전날) | 검사지 전체(A·B·C영역) |
| 프로그램 | 1~16차시 진행 | — |
| 사후 검사 | **16차시(마지막) 종료 후**(같은 날 정리 후 또는 다음 날) | **사전과 동일한 문항** |

같은 학생의 사전 점수와 사후 점수를 짝지어(대응시켜) 비교하는 것이 핵심이에요. 그래서 **익명 번호로 사전·사후를 연결**하는 장치가 꼭 필요해요(1.3 참조).

### 1.2 가능하면 — 비교집단 설계

여건이 되면 프로그램을 하는 학급(실험집단)과 하지 않는 비슷한 학급(비교집단)을 함께 검사하면, "정말 이 프로그램 때문에 달라졌는지"를 더 설득력 있게 말할 수 있어요.

- 두 집단 모두 **같은 시기에 사전·사후 검사**를 실시해요.
- 비교집단은 같은 학년·비슷한 환경의 학급이면 좋아요(완벽히 같을 필요는 없어요).
- 비교집단 학생에게도 익명 번호 원칙을 똑같이 적용해요.
- 여건상 어려우면 단일집단 설계만으로도 충분히 의미 있는 자료가 돼요. 무리해서 옆 반을 끌어들이지 않아도 괜찮아요.

### 1.3 무기명·번호표식 원칙 (개인정보 미수집)

- **이름을 적지 않아요.** 검사지 상단에 이름 칸 대신 **출석번호(또는 별도로 부여한 익명 번호)만** 적게 해요.
- 사전과 사후에 **같은 번호**를 쓰게 해서, 개인을 특정하지 않고도 같은 학생의 전후 응답을 짝지을 수 있어요.
- 공용 PC나 태블릿을 쓸 때, 게임 수료증에 넣는 이름도 **실명이 아닌 별명**을 쓰도록 안내해요(예: "알고리즘 탐정 김누리").
- 집계표·보고서에는 번호조차 남길 필요가 없어요. **학급 평균 등 집단 값**만 제시하면 돼요.
- 검사지 원본은 프로그램·연구 목적 외에 쓰지 않고, 정리가 끝나면 보관 기간을 정해 안전하게 폐기해요.

> 요약: **"이름은 안 적어요. 번호로만 짝짓고, 결과는 반 전체 숫자로만 말해요."**

## 2. 검사지 활용법 — 언제·어떻게 배부하고 회수할까

검사지 문항과 안내 멘트는 [`사전사후-검사지.md`](사전사후-검사지.md) 2부(학생용 본문)를 그대로 인쇄해 써요. 구성은 **A영역 리커트 19문항 + B영역 시나리오(선다형) 7문항 + C영역 서술형 2문항**이에요.

### 2.1 배부·회수 절차

1. **인쇄**: 검사지 2부(학생용)를 학생 수만큼 인쇄해요(A4 양면 1장 분량). 사전용·사후용을 따로 준비하고, 상단 '□ 사전 □ 사후' 칸에 표시하게 해요.
2. **익명 번호 안내**: "이름은 쓰지 말고, 출석번호만 적어요. 사후 검사 때도 **같은 번호**를 써야 해요"라고 안내해요.
3. **분위기 안내**: "시험이 아니고 점수도 성적에 안 들어가요. 지금 내 생각 그대로 솔직하게 답해 주세요."
4. **응답(약 15분)**: 개별로, 서로 상의 없이 응답하게 해요(A영역 6분·B영역 5분·C영역 3분 안내).
5. **회수**: 걷어서 번호순으로 정리해 두면 나중에 집계가 편해요.

### 2.2 실시할 때 유의점 (검사지 1부와 동일)

- **사전 검사에서는 정답·개념 설명을 하지 않아요.** "모르겠어요" 하는 학생에게는 "지금 아는 만큼만 쓰면 돼요"라고 안내해요. B·C영역 정답 확인은 **사후 검사까지 마친 뒤**에 해요.
- **사전 검사지는 사후 검사 전까지 돌려주지 않아요**(문항을 미리 학습하는 효과를 막기 위해서예요).
- 사전·사후 **문항이 완전히 같아야** 비교가 성립해요. 중간에 문항을 고치지 않아요.

## 3. 채점·집계 방법

### 3.1 A영역(리커트 19문항) — 점수 환산

문항별로 **① = 1점 ~ ⑤ = 5점**으로 환산해요. 응답 칸의 왼쪽부터 1·2·3·4·5점이에요.

- **역문항 처리**: 이 검사지의 A영역 19문항은 모두 **긍정 진술(그럴수록 바람직)** 로 작성되어 있어, ⑤에 가까울수록 높은 점수예요. 별도로 뒤집어 계산해야 하는 역문항은 없어요. (혹시 교사가 문항을 수정·추가해 '~하지 않아도 된다'처럼 부정 진술을 넣었다면, 그 문항만 `6 - 원점수`로 뒤집어 계산해요. 예: ②(2점) → 4점.)
- 무응답 칸은 빈칸으로 두고, 평균을 낼 때 **응답한 문항 수로만** 나눠요(빈칸을 0점으로 넣지 않아요).

### 3.2 영역별 합산

A영역은 검사지 3부 매핑표 기준으로 네(하위) 영역으로 묶여 있어요. 프로그램의 4대 축과도 대응돼요.

| 상위 축 | 하위 영역(검사지 기준) | 해당 문항 |
|---|---|---|
| 미디어 리터러시(추천·알고리즘) | 알고리즘 인식 | A1, A2, A3, A4 |
| AI 이해 | AI 인식 | A5, A6, A7, A8, A9, A17 |
| 디지털 시민성(디지털 생활) | 디지털 생활 인식 | A13, A14 |
| AI 윤리·실천(행동 의지) | 행동 의지 | A10, A11, A12, A15, A16, A18, A19 |

- **영역 점수 = 그 영역에 속한 문항 점수의 평균**(합계가 아니라 평균으로 내면 문항 수가 달라도 5점 만점으로 비교할 수 있어 편해요).
- 예: 알고리즘 인식 = (A1+A2+A3+A4) ÷ 4.
- **전체 A영역 점수 = 19문항 전체의 평균.**

### 3.3 학급 평균·전후 차이 계산 절차

1. 학생별로 각 영역 평균과 전체 평균을 사전·사후 각각 구해요.
2. **학급 평균** = 학생들 값의 평균(반 전체를 다시 평균).
3. **전후 차이(향상도)** = 사후 학급 평균 − 사전 학급 평균.
4. 영역별로 같은 방식으로 계산해, 어느 영역에서 변화가 컸는지 봐요.

예시 표현: "AI 이해 영역 평균 **2.8 → 4.1 (+1.3)**".

### 3.4 B영역(시나리오 7문항) — 정답률 비교

- 검사지 3부 정답표(B1③·B2②·B3②·B4③·B5②·B6③·B7②)로 채점해요.
- 문항별 **정답률(%) = 정답 학생 수 ÷ 응답 학생 수 × 100**을, 사전·사후로 비교해요.
- 오답 분포 변화도 함께 보면 좋아요(예: 사전엔 '그냥 믿는다'류 오답이 많다가 사후에 줄었는지).

### 3.5 C영역(서술형 2문항) — 수준 분포 비교

- 검사지 3부 수준별 기준(상/중/하)으로 사전·사후 응답을 각각 코딩해요.
- **수준 분포의 이동**을 비교해요(예: 하 60% → 상 40%·중 45%).
- 맞춤법·문장력은 보지 않고 **개념 포함 여부**만 봐요. 사전에 '하'가 많은 건 자연스러운 출발점이에요.

### 3.6 손집계표 양식

인쇄해서 걷은 검사지를 손으로 집계할 때 쓰는 표예요. 익명 번호로만 적어요(부록 A에 빈 양식이 더 있어요).

**A영역 문항별 집계표(예시 — 사전)**

| 익명번호 | A1 | A2 | A3 | … | A19 | 알고리즘 인식 평균 | AI 인식 평균 | 디지털 생활 평균 | 행동 의지 평균 | 전체 평균 |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 3 | 2 | 3 | … | 2 | 2.8 | 2.6 | 3.0 | 2.4 | 2.6 |
| 2 | | | | | | | | | | |
| … | | | | | | | | | | |
| **학급 평균** | | | | | | | | | | |

사후용 표를 같은 양식으로 하나 더 만들어, 맨 아래 '학급 평균' 줄만 두 표에서 뽑아 비교하면 돼요.

### 3.7 스프레드시트 집계 팁

엑셀·구글 시트로 하면 훨씬 빨라요. 개인정보 없이 **번호와 점수만** 입력해요.

- 한 행에 학생 한 명(익명 번호), 각 열에 A1~A19 점수를 입력해요.
- 영역 평균: 해당 영역 문항 범위의 **평균 함수**를 걸어요(일반식: `영역평균 = 그 영역 문항들의 평균`).
- 학급 평균: 학생들 값이 든 열에 다시 평균 함수를 걸어요.
- 전후 차이: `사후 학급 평균 − 사전 학급 평균`을 빼기 수식으로 계산해요.
- 향상 인원 비율: 학생별로 `사후 − 사전`을 계산한 열을 만들고, 그 값이 0보다 큰 사람 수를 세어(개수 세기 함수) 전체 인원으로 나눠요.
- B영역 정답률: 각 문항 열에 '정답이면 1, 아니면 0'을 넣고 평균을 내면 바로 정답률이 돼요.
- 시트 파일에도 이름·학번 대신 **익명 번호만** 저장하고, 보관·폐기 원칙(1.3)을 똑같이 지켜요.

## 4. 해석 가이드

### 4.1 전후 차이를 해석할 때 유의점

- **성숙효과·외부 영향**: 16차시가 진행되는 몇 주 동안 학생은 자라고, 다른 수업·가정·뉴스에서도 배워요. 단일집단 설계에서는 향상분이 오롯이 이 프로그램 덕분이라고 단정하기 어려워요. "프로그램과 함께 나타난 변화"로 신중하게 표현해요(비교집단이 있으면 더 강하게 말할 수 있어요).
- **표본(반 인원)이 작아요**: 초등 한 학급은 20~30명 수준이라, 숫자 한두 개에 크게 흔들려요. 소수점 둘째 자리까지 정밀하게 다투기보다 **경향(올랐다/영역 간 차이)** 중심으로 읽어요.
- **천장·바닥 효과**: 사전 점수가 이미 높은 문항은 더 오를 여지가 적고, 아주 낮은 문항은 조금만 올라도 크게 보여요. 문항의 출발점을 함께 봐요.
- **자기보고의 한계**: A영역은 '안다·하려 한다'는 **자기 보고**예요. 실제 행동과 다를 수 있으니, B·C영역(판단·서술)과 함께 읽으면 더 균형 잡혀요.

### 4.2 정성 관찰을 함께 (권장)

수치만으로는 놓치는 변화가 많아요. 다음 정성 자료를 함께 모아 삼각 검증(여러 근거로 교차 확인)하면 훨씬 설득력이 커져요.

- **수업 소감**: 차시 끝 소감, 프로그램 전체를 마친 뒤 한 줄 소감.
- **학습지**: 각 차시 학습지의 '사고 확장'·'실천 다짐' 칸 변화.
- **모둠 산출물**: 모둠 활동지, 12차시 '우리 반 단톡방 약속 카드', 4부 산출물 등.
- **대표 사례**: C영역 사전·사후 답을 나란히 놓은 사례 2~3건(익명 번호로만 인용)은 보고서의 좋은 질적 근거가 돼요.

## 5. 간이 통계 — 초등 현장 수준

복잡한 통계 없이도 충분히 보고할 수 있어요. 아래 세 가지면 학급 단위 변화를 잘 보여 줘요.

1. **평균차(향상도)**: 영역별·전체의 `사후 평균 − 사전 평균`.
2. **향상 인원 비율**: `사후가 사전보다 오른 학생 수 ÷ 전체 학생 수 × 100`. "학급의 몇 %가 향상됐는가"는 직관적이고 힘이 있어요.
3. **B영역 정답률 변화**: 문항별 정답률의 전후 차이(%p).

> **더 엄밀히 하고 싶다면**: 사전·사후 평균의 차이가 통계적으로 의미 있는지 확인하려면 **필요시 대응표본 t검정** 등을 쓸 수 있어요. 비교집단이 있으면 독립표본 t검정이나 공분산분석(ANCOVA)도 고려할 수 있고요. 다만 초등 학급 규모에서는 위의 간이 지표와 정성 자료를 함께 제시하는 것만으로도 연구대회 보고서로 충분해요. 검정을 넣을 때도 **개인 식별 없는 집단 데이터**로만 계산해요.

## 6. 결과 정리·보고 체크리스트

- [ ] 검사지에 이름 없이 **익명 번호만** 있는가.
- [ ] 사전·사후를 **같은 번호로 짝지었는가.**
- [ ] 결과를 **학급 평균 등 집단 통계**로만 제시했는가(개별 학생이 드러나지 않는가).
- [ ] A(인식)·B(판단)·C(서술) **세 영역을 함께** 제시했는가.
- [ ] 향상도와 함께 **해석의 한계**(성숙효과·표본·자기보고)를 밝혔는가.
- [ ] 수치에 **정성 관찰**을 곁들였는가.
- [ ] 원본 검사지·집계 파일의 **보관·폐기 기준**을 정했는가.
