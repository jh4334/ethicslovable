# 미디어 리터러시 퀘스트 — 통합 세계관 설정집

4개 게임이 공유하는 가상 세계관입니다. 상표권·초상권 문제를 피하고
공모전 스토리텔링을 강화하기 위해, 모든 서비스·인물·콘텐츠는 아래
설정 안에서만 등장합니다. **실존 브랜드·인물·프로그램 이름은 어떤
게임에도 등장하지 않습니다.**

## 세계관 개요

> 인터넷 세상 **"누리마을"** 에는 모두가 쓰는 앱을 만드는 회사
> **"누리소프트"** 가 있어요. 플레이어(학생)는 누리소프트에 새로 들어온
> **새내기 알고리즘 요원**이 되어, 4개의 퀘스트를 차례로 통과하며
> 추천 알고리즘의 비밀을 배웁니다.

- 회사: **누리소프트** — 누리마을의 대표 IT 회사
- SNS 앱: **누리피드** — 사진·글·영상을 공유하는 SNS (1·2·3차시 무대)
- 동영상 앱: **누리TV** — 동영상 추천 플랫폼 (4차시 무대)
- 플레이어 역할: 새내기 알고리즘 요원 (차시가 오를수록 직급 상승)

## 차시별 배치

| 차시 | 게임 | 세계관 속 역할 |
|---|---|---|
| 1차시 | 알고리즘 설계자 | 누리피드 **알고리즘 설계실**에 배치되어 7일 근무 |
| 2차시 | 필터버블 탐지기 | 누리피드의 **성향 분석 실험실**에서 내 선택 성향을 직접 실험 |
| 3차시 | 추천 요정 훈련소 | 누리피드의 **추천 요정**이 되어 추천 훈련 |
| 4차시 | 알고리즘 연구소장 | **누리TV 알고리즘 연구소**의 소장으로 승진 |

## 공용 가상 IP 목록 (게임 속 콘텐츠에서 참조)

실존 게임·방송·연예인 대신 아래 가상 IP만 사용합니다. 새 IP가 필요하면
이 문서에 추가하고 여러 게임이 재사용합니다.

### 게임
- **전설의 수호자** — 5:5 대전 게임 (롤 대체)
- **네모월드** — 블록 쌓기 창작 게임 (마인크래프트 대체)
- **달리는 감자** — 캐주얼 달리기 게임
- **아일랜드 서바이벌** — 무인도 생존 게임

### 방송·콘텐츠
- **한글 왕중왕전** — 우리말 퀴즈 쇼
- **누리마을 뉴스** — 마을 소식 뉴스 채널
- **요리왕 뚝딱** — 어린이 요리 크리에이터
- **과학쌤 호기심** — 과학 실험 크리에이터
- **몽실이** — 누리마을에서 제일 유명한 강아지 스타
- **은하수 다섯** — 5인조 아이돌 그룹

### 장소·행사
- **누리랜드** — 놀이공원 (디즈니랜드 대체)
- **무지개시장** — 전통시장 겸 쇼핑 명소
- **누리마을 골목축제** — 계절 축제

## 콘텐츠 작성 규칙 (초등 5~6학년)

1. 문체는 **해요체**로 통일해요.
2. 실존 브랜드·인물·프로그램·게임·지역 상호 금지 → 위 가상 IP로 대체.
3. 성인 소재는 **어린이 시점으로 순화해 일부 유지** — 예: 주식 → "어른들은 왜 주식 얘기를 할까?", 명품 소비 → "용돈을 다 써 버렸어요".
   폭력·연애·도박·음주·사행성·외모 비하 소재는 금지 (뽑기류는 소비 습관 관점으로만).
4. 낚시성·자극성 표현은 교육 목적상 필요하므로 **초등 안전 범위 안에서 유지** — 예: "충격! 급식에서 이게 나왔다?!".
5. 로마자 표기는 사전에 등재된 일반어(TV, SNS)만 허용. ASMR·OOTD·LOL 같은
   은어성 로마자는 한글 표현으로 바꿔요.
