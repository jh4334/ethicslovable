# 미디어 리터러시 퀘스트 — 통합 세계관 설정집

4개 게임이 공유하는 가상 세계관입니다. 상표권·초상권 문제를 피하고
공모전 스토리텔링을 강화하기 위해, 모든 서비스·인물·콘텐츠는 아래
설정 안에서만 등장합니다. **실존 브랜드·인물·프로그램 이름은 어떤
게임에도 등장하지 않습니다.**

## 세계관 개요

> 인터넷 세상 **"누리마을"** 에는 모두가 쓰는 앱을 만드는 회사
> **"누리소프트"** 가 있어요. 플레이어(학생)는 누리소프트에 새로 들어온
> **새내기 알고리즘 요원**이 되어, 4개의 퀘스트를 차례로 통과하며
> 추천 알고리즘의 비밀을 배웁니다.

- 회사: **누리소프트** — 누리마을의 대표 IT 회사
- SNS 앱: **누리피드** — 사진·글·영상을 공유하는 SNS (1·2·3차시 무대)
- 동영상 앱: **누리TV** — 동영상 추천 플랫폼 (4차시 무대)
- 플레이어 역할: 새내기 알고리즘 요원 (차시가 오를수록 직급 상승)

## 차시별 배치

### 1부 · 알고리즘의 비밀 (1~4차시)

| 차시 | 게임 | 세계관 속 역할 |
|---|---|---|
| 1차시 | 알고리즘 설계자 | 누리피드 **알고리즘 설계실**에 배치되어 7일 근무 |
| 2차시 | 필터버블 탐지기 | 누리피드의 **성향 분석 실험실**에서 내 선택 성향을 직접 실험 |
| 3차시 | 추천 요정 훈련소 | 누리피드의 **추천 요정**이 되어 추천 훈련 |
| 4차시 | 알고리즘 연구소장 | **누리TV 알고리즘 연구소**의 소장으로 승진 |

### 2부 · 인공지능과 살아가기 (5~8차시)

1부를 마친 플레이어는 누리소프트의 **AI 연구소**로 스카우트된다.

| 차시 | 게임 | 세계관 속 역할 |
|---|---|---|
| 5차시 | 데이터 편식쟁이 AI | AI 연구소의 **AI 훈련사** — 새내기 AI '아기봇'에게 세상을 가르침 |
| 6차시 | 딥페이크 탐정단 | 누리마을 **가짜 콘텐츠 수사대** 탐정 |
| 7차시 | 누리봇 사실 검증단 | AI 비서 '누리봇'의 답변을 검증하는 **사실 확인 요원** |
| 8차시 | 내 데이터의 여행 | 내 데이터가 어디로 가는지 추적하는 **데이터 여행자** |

### 2부 추가 등장 캐릭터
- **누리봇** — 누리소프트가 만든 AI 비서. 아는 것도 많지만 가끔 그럴듯한
  거짓말(환각)을 한다. 절대 악당이 아니라 "잘 쓰려면 확인이 필요한 도구".
- **아기봇** — 훈련 중인 새내기 AI. 먹은(학습한) 데이터만큼만 세상을 안다.

## 공용 가상 IP 목록 (게임 속 콘텐츠에서 참조)

실존 게임·방송·연예인 대신 아래 가상 IP만 사용합니다. 새 IP가 필요하면
이 문서에 추가하고 여러 게임이 재사용합니다.

### 게임
- **전설의 수호자** — 5:5 대전 게임 (롤 대체)
- **네모월드** — 블록 쌓기 창작 게임 (마인크래프트 대체)
- **달리는 감자** — 캐주얼 달리기 게임
- **아일랜드 서바이벌** — 무인도 생존 게임

### 방송·콘텐츠
- **한글 왕중왕전** — 우리말 퀴즈 쇼
- **누리마을 뉴스** — 마을 소식 뉴스 채널
- **요리왕 뚝딱** — 어린이 요리 크리에이터
- **과학쌤 호기심** — 과학 실험 크리에이터
- **몽실이** — 누리마을에서 제일 유명한 강아지 스타
- **은하수 다섯** — 5인조 아이돌 그룹

### 장소·행사
- **누리랜드** — 놀이공원 (디즈니랜드 대체)
- **무지개시장** — 전통시장 겸 쇼핑 명소
- **누리마을 골목축제** — 계절 축제

## 콘텐츠 작성 규칙 (초등 5~6학년)

1. 문체는 **해요체**로 통일해요.
2. 실존 브랜드·인물·프로그램·게임·지역 상호 금지 → 위 가상 IP로 대체.
3. 성인 소재는 **어린이 시점으로 순화해 일부 유지** — 예: 주식 → "어른들은 왜 주식 얘기를 할까?", 명품 소비 → "용돈을 다 써 버렸어요".
   폭력·연애·도박·음주·사행성·외모 비하 소재는 금지 (뽑기류는 소비 습관 관점으로만).
4. 낚시성·자극성 표현은 교육 목적상 필요하므로 **초등 안전 범위 안에서 유지** — 예: "충격! 급식에서 이게 나왔다?!".
5. 로마자 표기는 사전에 등재된 일반어(TV, SNS)만 허용. ASMR·OOTD·LOL 같은
   은어성 로마자는 한글 표현으로 바꿔요.

### 3부 · 슬기로운 누리 생활 (9~12차시)

AI 연구소 수료 후, 플레이어는 **누리마을 지킴이**로 임명되어 마을 사람들이
매일 쓰는 앱들의 설계를 점검한다.

| 차시 | 게임 | 세계관 속 무대 |
|---|---|---|
| 9차시 | 멈출 수 없는 화면 | 숏폼 앱 **누리숏** — 세로로 넘기는 짧은 영상 |
| 10차시 | 뽑기 상자의 비밀 | 게임 '전설의 수호자'의 **아이템 상점** |
| 11차시 | 검색 결과 탐정 | 검색 포털 **누리찾기** |
| 12차시 | 단톡방을 지켜라 | 메신저 **누리톡**의 우리 반 단톡방 |

### 3부 추가 서비스
- **누리숏** — 누리소프트의 숏폼 영상 앱. 다음 영상이 뭔지 몰라 자꾸 넘기게 된다.
- **누리찾기** — 누리마을 검색 포털. 광고 결과에는 작게 '광고' 표시가 붙는다.
- **누리톡** — 누리마을 국민 메신저. 우리 반 단톡방이 있다.
