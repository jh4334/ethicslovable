# 새 게임(차시) 추가 체크리스트

새로운 차시 게임을 하나 붙일 때 빠뜨리기 쉬운 연결점을 모았습니다. 순서대로 확인하면
포털 진행률·수료증·라우팅·검증까지 어긋나지 않게 이어집니다.

## 1. 게임 코드

- [ ] `src/games/<game-id>/` 폴더 생성 (`index.tsx`가 기본 export)
- [ ] 콘텐츠는 코드와 분리해 `src/content/<game-id>.json`으로
- [ ] 콘텐츠 로딩은 `loadContent("<game-id>", fallback)` 사용 (오프라인 fallback 필수)
- [ ] 게임별 스타일은 `.game-<id>` 스코프 아래에만 (다른 게임 오염 방지)
- [ ] 결과 화면에서 `useMarkCompleted("<game-id>", 요약문구, 점수?)` 훅 호출
      (StrictMode 이중 실행에도 1회만 기록 — 직접 `markCompleted` + ref 가드를 새로 쓰지 말 것)

## 2. 레지스트리 (두 곳을 반드시 함께)

- [ ] `src/lib/progress.ts` — `GameId` 유니온과 `GAME_IDS` 배열에 새 id 추가
- [ ] `src/portal/games.ts` — `GAMES`에 메타(lesson·chapter·title·goal·minutes·emoji·path) 추가
- [ ] `LESSON_HUES`(`PortalPage.tsx`·`CertificatePage.tsx`)에 차시 색상 추가
- [ ] ✅ `npm test`의 "게임 레지스트리 정합성" 통과 확인 (두 목록 불일치를 잡아 줌)

## 3. 라우팅

- [ ] `src/App.tsx` — `lazyGame(() => import("./games/<game-id>"))` + `<Route>` 추가

## 4. 콘텐츠 검증

- [ ] `scripts/validate-content.mjs`에 새 콘텐츠의 구조·참조 규칙 추가
- [ ] 순수 로직이 있으면 `src/games/<game-id>/*.test.ts`로 단위 테스트
- [ ] ✅ `npm run validate:content` · `npm test` 통과

## 5. 문서

- [ ] `README.md` — 차시 표·콘텐츠 표에 행 추가
- [ ] `docs/worldview.md` — 새 등장인물·용어가 있으면 세계관에 반영
- [ ] `docs/teacher/` — 지도안·학습지·모둠활동지(필요 시)

## 6. 최종 검증

- [ ] `npm run typecheck && npm run build && npm run build:offline`
- [ ] `npm run e2e` — 새 라우트를 `scripts/e2e-smoke.mjs`의 ROUTES에 추가한 뒤 전체 로드 스모크 통과
- [ ] 웹·오프라인(file://) 양쪽에서 새 게임 진입·완료·수료증 반영 확인
