## 1. 개요

| 항목 | 내용 |
|---|---|
| 작품명 | 미디어 리터러시 퀘스트 |
| 대상 | 초등학교 5~6학년 |
| 형태 | 설치·로그인 없이 브라우저만으로 실행되는 웹 게임 16종 (4부 16차시) + 교사용 지도안·학습지·모둠활동지·성취기준 매핑 |
| 실행 환경 | PC·태블릿 웹 브라우저 (인터넷 연결 없이 단일 HTML 파일로도 실행) |
| 개인정보 | 일절 수집하지 않음 (서버·로그인 없음, 진행 기록은 사용 브라우저에만 저장) |

**한 줄 요약** — 학생이 알고리즘·인공지능·앱 속 설계를 '소비자'가 아니라 '설계자·검증자·지킴이·바르게 쓰는 사람'의 자리에 앉아 직접 겪어 보는, 설치도 로그인도 개인정보 수집도 없는 16차시 게임 기반 미디어·AI 리터러시 수업 패키지예요.

「미디어 리터러시 퀘스트」는 초등학교 5~6학년 학생이 가상 인터넷 마을 '누리마을'의 IT 회사 '누리소프트'에 입사한 새내기 요원이 되어, 16개의 퀘스트(게임)를 차례로 수행하며 추천 알고리즘과 인공지능의 원리·영향, 매일 쓰는 앱 속 설계, 그리고 AI를 직접 쓰는 사람의 태도를 배우는 웹 게임 기반 수업 자료예요. 게임 16종을 학습 순서(차시)대로 배치한 통합 포털, 차시별 40분 지도안, 인쇄용 학습지·모둠활동지 각 16종, 2022 개정 교육과정 성취기준 매핑표(4부는 충북형 AI 윤리 가이드라인 병기)를 하나의 패키지로 구성했어요.

## 2. 개발 배경과 필요성

### 가. 추천 알고리즘과 생성형 AI가 일상이 된 교실

지금 5~6학년 교실에서는 상당수 학생이 영상 플랫폼과 SNS의 추천 피드, 그리고 생성형 AI를 일상적으로 이용하고 있어요. 그러나 "그 영상, 네가 골랐니? 누가 골라 줬니?"라고 물으면 대부분 명확히 답하지 못해요. 학생들은 추천 시스템과 AI의 가장 열성적인 이용자이면서, 그 작동 원리에 대해서는 거의 알지 못하는 상태에 있어요.

### 나. 기존 교육 자료의 한계

- **개별 콘텐츠 중심** — 기존 미디어·정보통신윤리 교육은 저작권, 사이버 폭력 예방, 가짜 뉴스 판별 등 개별 콘텐츠를 다루는 태도에 집중된 경우가 많았어요. 그러나 학생이 무엇을 보게 될지를 사실상 결정하는 것은 개별 콘텐츠 이전에 '추천 알고리즘이라는 구조'예요. "알고리즘이 왜 이 영상을 보여 주는가", "내 데이터가 나를 어떻게 분류하는가", "AI는 어떻게 배우고 어디까지 믿을 수 있는가"를 초등 눈높이에서 다루는 자료는 찾기 어려웠어요.
- **개인정보 수집·외부 플랫폼 의존** — 회원가입·로그인을 요구하거나 외부 상용 플랫폼에 접속해야 하는 자료는 학생 개인정보 수집에 대한 우려와 계정 관리 부담을 낳아요.
- **저사양·오프라인 미대응** — 인터넷이 불안정한 교실, 설치 권한이 없는 공용 PC, 보안망으로 외부 접속이 막힌 교실에서는 실행 자체가 어려운 자료가 많았어요.

### 다. "설명하지 말고, 그 자리에 앉혀 보자"

알고리즘과 AI의 구조는 말로 설명하기보다 그 자리에 직접 앉아 보게 하는 것이 빠르다고 판단했어요. 그래서 학생이 알고리즘을 설계하고, 자신이 분석당해 보고, AI를 직접 훈련시키고, 앱 속 설계를 겪은 뒤 해부하고, AI를 직접 쓰는 사람이 되어 보는 16차시 체험 게임을 개발했어요. 아울러 학교 현장의 제약(불안정한 인터넷, 설치 권한 없는 공용 PC, 개인정보 우려)을 처음부터 설계 조건으로 삼았어요.

## 3. 작품 목적과 학습 목표

본 작품은 미디어·AI 리터러시를 4부 체계로 나누어, 부가 오를수록 학생의 시점이 '바깥에서 보는 사람'에서 '직접 다루는 사람'으로 확장되도록 설계했어요.

| 부 | 주제 | 핵심 학습 목표 |
|---|---|---|
| 1부 · 알고리즘의 비밀 | 추천 알고리즘 | 추천 알고리즘의 기준·이익 구조와 필터버블을 이해하고, 설계자·데이터·알고리즘·운영자의 네 관점에서 추천 시스템을 비판적으로 바라봐요. |
| 2부 · 인공지능과 살아가기 | 인공지능 | AI가 데이터로 배우는 원리와 데이터 편향을 체험하고, AI 생성물 판별·환각 검증·개인정보 보호를 통해 AI를 확인하며 부리는 태도를 길러요. |
| 3부 · 슬기로운 누리 생활 | 디지털 생활 | 매일 쓰는 앱(숏폼·게임 상점·검색 포털·메신저) 속 설계를 직접 겪고 해부하며, 자기 조절·현명한 소비·검색 리터러시·공동체 예절을 실천해요. |
| 4부 · AI와 바르게 쓰기 | AI 윤리 | AI를 직접 쓰는 사람으로서 안전·공정·책임·성장의 4대 가치를 체험하고, 안전하고 공정하며 책임 있게, 그리고 주도적으로 AI를 쓰는 태도를 익혀요. |

각 부는 한 차시에 한 걸음씩 나아가, 1부 수료 시 같은 추천 화면을 네 관점에서 겪어 본 상태가 되고, 4부 수료 시에는 AI를 스스로 안전·공정·책임 있게 부리는 태도를 갖추게 돼요.

## 6. 차별점과 특장점

### ① 개인정보 수집 0 — 서버도 로그인도 없어요

로그인·회원가입·서버 전송이 전혀 없고, 진행 기록은 사용 중인 브라우저(localStorage)에만 남아요. 나아가 이 원칙을 문서(`index.html`)의 **콘텐츠 보안 정책(CSP)**으로 브라우저 차원에서 강제해, 같은 출처의 데이터 파일만 불러오고 어떤 외부 서버로도 데이터를 보내지 못하게 막았어요. 13차시에 등장하는 개인정보 예시(이름·전화번호·비밀번호 등)도 모두 가상 인물의 예시일 뿐, 학생이 자기 정보를 입력하거나 저장하는 일은 일어나지 않아요.

### ② 가상 세계관 '누리마을' — 실존 브랜드·인물·뉴스 배제

16개 게임은 가상 세계관 '누리마을'을 공유해요. 게임 속 SNS(누리피드), 동영상 플랫폼(누리TV), 숏폼 앱(누리숏), 검색 포털(누리찾기), 메신저(누리톡), AI 비서(누리봇)와 등장인물·게시물·뉴스는 모두 교육용으로 창작한 가상 콘텐츠이며, **실존 브랜드·인물·프로그램 이름은 어떤 게임에도 등장하지 않아요**(세계관 설정집 `docs/worldview.md`에 명문화). 덕분에 상표권·초상권 문제없이 학교 안팎 어디서나 배포할 수 있고, 특정 앱을 홍보하거나 비난하는 수업이 되지 않아요.

### ③ 오프라인 단일 파일 실행 — 저사양·학교망 대응

외부 폰트·CDN·API에 의존하지 않고, 단일 HTML 파일(`dist-offline/index.html`) 하나를 USB·메신저로 배포하면 인터넷 없는 교실 PC에서도 더블클릭으로 실행돼요. 한글 폰트(Pretendard)도 파일 안에 내장해, 보안망으로 외부 접속이 막힌 교실이나 저사양 기기에서도 동작하도록 구성했어요.

### ④ 교사가 코드 없이 JSON으로 콘텐츠 수정

게임 속 게시물·카드·미션 문구는 전부 코드와 분리된 JSON 파일(`src/content/*.json`)에 있어, 코드를 몰라도 메모장으로 열어 고칠 수 있어요. 웹 배포본에서는 `data/*.json`을 수정하면 재빌드 없이 바로 반영돼요. 각 파일 첫머리에 교사용 수정 안내문을 한글로 내장해, 어떤 항목을 고쳐도 되는지를 파일 안에서 확인할 수 있어요.

### ⑤ 배지·수료증·학습지·모둠활동지·지도안 완비

게임만 있는 것이 아니라, 차시별 40분 지도안(핵심 발문·오개념 주의·평가 관점 포함), 인쇄용 학습지 16종과 모둠활동지 16종, 성취기준 매핑표, 세계관 설정집, 콘텐츠 검수표까지 하나의 패키지로 갖췄어요. 미디어 교육 경험이 없는 교사도 URL 공유(또는 파일 배포) 하나로 곧바로 수업에 적용할 수 있어요.

## 7. 기대 효과

### 가. 학생 측면

- **구조를 보는 눈** — 추천 화면을 '저절로 뜨는 것'이 아니라 "누군가 정한 규칙(가중치)에 따라 만들어지는 것"으로 인식하게 돼요.
- **균형 잡힌 태도** — "알고리즘·AI는 악당"이라는 냉소도, 무비판적 수용도 아닌 "도구일 뿐 — 무엇을 볼지·어떻게 쓸지 정하는 건 나 자신"이라는 도달점에 이르러요.
- **자기 조절과 실천** — 필터버블 성찰, 숏폼 시간 관리, 확률 계산, 단톡방 약속 만들기, AI 안전·창작 약속으로 이어지는 실천 태도를 길러요.

### 나. 교사 측면

- 지도안·학습지·평가 관점·발문이 일습으로 제공되고 사전 준비가 URL 공유 하나로 끝나, 미디어 교육 경험이 없어도 곧바로 적용할 수 있어요.
- JSON 콘텐츠 수정으로 학급·학교 실태에 맞춘 '우리 반 버전' 재구성이 가능해요.

### 다. 보급 측면

- 개인정보를 수집하지 않고 설치·로그인이 필요 없어, 교육청·학교의 개인정보·보안 심사 부담 없이 전국 어느 교실에나 배포할 수 있어요.
- 무서버·저비용 구조(정적 호스팅 또는 단일 파일)로 운영 비용 없이 URL 공유·파일 전달만으로 확산할 수 있어요.

## 8. 활용 방법

### 가. 학교 환경별 배포 방법

| 학교 환경 | 배포 방법 |
|---|---|
| 인터넷 사용 가능 (PC실·태블릿) | 배포된 URL 접속만으로 즉시 실행. 정적 호스팅으로 별도 서버 없이 운영 가능 |
| 인터넷 없음·보안망 교실 | 단일 HTML 파일(`dist-offline/index.html`)을 USB·메신저로 배포 → 교실 PC에서 더블클릭 실행 |
| 학교 자체 서버·내부망 | 빌드 결과물(`dist/` 폴더)을 학교 정적 서버에 업로드. `data/*.json`만 고치면 재빌드 없이 콘텐츠가 바로 반영 |

### 나. 실행 절차 (교사·개발자)

```
npm install            # 최초 1회
npm run dev            # 개발 서버 미리보기
npm run build          # dist/ — 웹 서버 업로드용 (data/*.json 수정 가능)
npm run build:offline  # dist-offline/index.html — 단일 파일, 더블클릭 실행
```

어느 방식이든 설치·로그인이 필요 없어요. 수업 전 교사가 각 게임을 1회 이상 플레이해 소요 시간과 결과 화면을 확인해 두길 권장해요.

### 다. 콘텐츠 수정 방법

게임 텍스트(게시물·카드·미션)는 전부 JSON 파일에 있어요. 원본은 `src/content/*.json`을 고친 뒤 다시 빌드하고, 웹 배포본은 `dist/data/*.json`을 고치면 재빌드 없이 바로 반영돼요. 단, 오프라인 단일 파일 버전은 콘텐츠가 파일 안에 내장되므로 수정 후 `npm run build:offline`을 다시 실행해야 해요. 수정 시 세계관 설정집(`docs/worldview.md`)의 초등 안전 기준(가상 IP만 사용, 소재 제한)을 함께 지켜 주세요.

### 라. 수업 절차 (차시 공통 흐름, 40분)

| 단계 | 내용 |
|---|---|
| 도입 (5분) | 학생의 실제 이용 경험을 끌어내는 발문 → 이번 차시 역할(직급) 안내 |
| 전개 (25분) | 게임 플레이(10~15분) → 짝과 결과 비교 → 교사 순회 발문 |
| 정리 (10분) | 핵심 발문 중심 전체 토의 → 성찰 문구를 함께 읽고 학습지에 실천 다짐 기록 |
